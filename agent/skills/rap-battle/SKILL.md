# 饶舌对决（rap battle）

一场对决＝**两位真实人物各唱一整首歌互呛**，DJ 主持开场、换场、收尾，最后留言投票。横式 3–4 分钟，观众是一般人。
制作工具是 `pipeline/template_battle/`（`battle.json`＋`make_battle.py`），本技能负责「想清楚、写好、生好歌、交给范本、审片」。

## 开工必读

1. `references/design.md`：选题、人物、DJ、结局、配色（**每场配色跟前几场不同**）。
2. `references/lyrics.md`：歌词规则（押法混用、唱段像流行副歌、杀句、两边一起改、读音）。
3. `references/songs.md`：生歌（**先问使用者有没有 Suno**）、检查、两首怎么接。
4. `references/video-spec.md`：影片规格、镜表写法、H3 规则、特效。
5. `references/review-checklist.md`：交片前逐秒自审。
6. 范本说明 `pipeline/template_battle/README.md`；H3、首帧的通用规则 `docs/03_规则与踩坑.md`、`docs/07_本地角色与首帧.md`。

## 阶段与关卡

每阶段交付后列 3–5 条自检，等使用者说「通过」或给修改才往下（使用者说「直接做到好」才跳过关卡，但自检照做）：

| 阶段 | 交付 | 关卡 |
|:--|:--|:--|
| 1 研究 | 两位人物的史实、争议点、可对到现代观众的梗（附出处） | 史实可查、梗一般人懂 |
| 2 对决设计 | 片名、谁先出场、DJ 是谁与为什么、结局（反转或定论）、投票打什么字、配色 | `design.md` 检查表 |
| 3 歌词 | 两首完整歌词＋**两边对照表**（A 丢的每个点 B 怎么接） | `lyrics.md` 检查表 |
| 4 生歌 | 每人各抽 2–4 版，挑好的给使用者试听（附逐句听写低分句） | 使用者听过说可以 |
| 5 角色定妆 | 两位饶舌手＋DJ 参考照（三人脸型、胡型、头饰都不同） | 使用者选定 |
| 6 镜表 | `battle.json` 的 shots（50–60 镜）、字卡文字 | 每句歌词都有对应画面 |
| 7 成片 | `make_battle.py` 一路做到 v1 | 自审（下方）→ 使用者审片 |

## 生歌：先问

**开始生歌前一定先问使用者：「你有 Suno 帐号吗？」**
- 有 → 用 Suno（网页 Custom 模式贴 `out/songtext/suno_*`，或 Kie API `kie_suno.py`）。编曲最丰富、rap 最有攻击性、会有刷碟声。
- 没有 → 问要不要改用本机 **YuE2 14 版范本**（`templates/song_yue2_v14/`），说清楚：攻击性和韵律感比 Suno 弱、权重 CC BY-NC 不能商用。不要自己默默换。
- YuE2 也不满意 → Plan C **ACE-Step 1.5**（`tools/ace_song.py`，拍速最稳、MIT 可商用，但人声有金属声）。
- 本机跑不动 YuE2 的人：Colab 完整安装已预装 YuE2，`python cloud/colab_h3.py film <对决资料夹> yue` 在云端生歌；有 Suno 还是最省事。

## 自审（交片前一定做）

`make_battle.py review` 产生每秒一格的接触表与自己切镜侦测，照 `references/review-checklist.md` 一张张看，问题列成清单（时间、镜号、问题、处理）→ 修 → 再出一版再看一次。**送给使用者的是 v1 和问题清单，最后一定要人看完整成片。**

## 共同规则

- **两人各一首完整的歌**：同一首歌里分两个人，声音会是同一个人；Suno 的 extend 接第二人也会变回第一人。
- **一呛一笑**：一人唱的时候，另一人闭嘴、不屑微笑（反应镜、双人同框都一样）。
- **观众是一般人**：典故太难就换现场梗；每个转折要有一句歌词、一张字卡或一个画面讲白；传说要写「传说」，数字要有出处。
- **配色、封面每场都换**：开工先列最近 2–3 场用过的配色，选一套贴题材、又不一样的（场景灯光、字幕、特效、字卡、封面一起换）。
- DJ 口白预设用 **Ming-3.0-TTS**（MIT，可商用；`make_battle.py dj`）。参考音预设由 Breeze TTS 2 依文字设计（不能商用）→ 要营利就自己录一段 10–20 秒放 `out/voice/ref_K.wav`。
- 授权：Suno 看你的方案（免费方案通常不能商用）；YuE2 权重、Qwen-Image 2.1、Breeze TTS 2 都不能商用；MiniMax H3 授权排除美、欧盟、英、南韩（Colab 机房在美国／欧盟：照常使用，工具会显示警语，风险自负）。公开时标示 AI 生成。
