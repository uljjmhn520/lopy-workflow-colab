# 影片规格与镜表

## 规格

| 项目 | 值 |
|:--|:--|
| 画面 | **横式**：H3 1344×768 → 成片 1920×1080、24 fps；手机版 1280×720 约 27 MB |
| 长度 | 3–4 分钟（两首歌＋开场＋片尾约 8 秒投票卡） |
| 镜数 | 50–60 镜：开场 3–5、A 约 22、换场 3–5、B 约 24、收尾 3–4 |
| 每镜 | 1–6 秒（跟著歌词一句一镜）；H3 每镜 ≤ 12 秒 |
| 声音 | −16 LUFS、真峰值 ≤ −1 dBTP；观众欢呼垫在攻击后与片尾 |

## 结构

| 段落 | 内容 |
|:--|:--|
| 开场 | 观众视角擂台全景＋片名卡 → DJ 喊开场（名牌）→ A、B 各自上台 → 两人对峙（VS 卡，静态慢推） |
| ROUND 1 | A 演唱镜（第一镜附名牌）穿插：**闪回／插入镜**（歌词讲到的事件）、**B 的不屑反应镜**、**观众 B-roll**、双人同框（A 唱、B 闭嘴）；最后一句杀招用胸上近景 |
| 换场 | 观众「喔～」→ DJ 刷碟特写 → DJ 指向 B（静态）→ B 卷袖、走到麦克风 |
| ROUND 2 | 同上，换 B 唱、A 反应；B 的杀句后观众爆炸 |
| 收尾 | 观众欢呼丢纸 → （定论／反转插入镜＋DJ 口白）→ 两人互相点头或背对赌气 → DJ 片尾三拍「谁赢了？下一场是谁？你决定！」→ 投票卡 |

## 镜型

| 类型 | 写法 |
|:--|:--|
| 演唱镜 | `kind: "sing"`；腰上（MCU）或胸上（CU），**主角不用全身远景**（脸会糊）。动作写**慢而清楚**的手势：手放胸口、指向对手、数手指、比耳朵听不到；**不要写甩手、劈砍、两手乱挥**（会糊）；加 `calm: true` |
| 反应镜 | `kind: "silent"`；闭嘴、不屑微笑、翻白眼、抱胸；会自己切镜的加 `last_first: true` |
| 双人同框 | `subj` 第一位是唱的人；`cons` 写「右边的人全程闭嘴、双手交叉不动」 |
| 闪回／插入 | 歌词讲到的事件（年代场景）、现代教室；`scene` 指到 `places` 的一个地点；不放麦克风、舞台灯 |
| 观众 B-roll | `subj: ["T"]`、全景；同步动作（举手、跳、丢纸） |
| DJ | 短的正面喊话镜（`kind: "sing", voice: "dj"`）＋刷碟特写；长口白放画外 |
| 静态 | `still: true`＝首帧慢推（VS 对峙、DJ 指向）；`custom`＝自己做的影片（精准的数学图解、图表） |

## at（镜头开始时间）

| 写法 | 意思 |
|:--|:--|
| `0.0` | 秒数（只有第一镜用） |
| `["A", 3]` | A 第 4 句（从 0 算）开口前 0.12 秒；`["A", -1]`＝A 第一句前 4 秒、`-2`＝前 2.5 秒 |
| `["dj", "switch", -0.3]` | DJ 换场口白开始前 0.3 秒（open／switch／verdict／end） |
| `["mark", "a_stop", 0.3]` | 时间点＋偏移：`a_first`（A 第一句）、`a_stop`（A 收尾拍）、`b_zero`（B 那首的 0 秒）、`b_first`、`b_last`（B 最后一个字）、`music_end` |

每镜的结束＝下一镜的开始；两镜不能短于 0.8 秒（程式会挡）。

## 首帧规则

- 首帧画「**动作开始前**」的姿势，不要画动作最高点。
- 擂台：左右两半是两人的配色，**地板只有金色圆环**（不要星形、符号），**不要旗子、布条、国徽、招牌字**。
- 一人一支麦克风，固定在原位。
- 书、黑板、萤幕上要出现的字写在 `frame` 里、用双引号；其他地方一律不要字。
- 两位饶舌手和 DJ 的脸型、胡型、头饰要一眼分得出来（同一系列也不要撞脸）。
- **真人感写法（全专案预设，2026-10-31）**：好看＋3–5 个具体特征、看得到毛孔、单一实际光源、手抓物；不写 photorealistic／8K／flawless（会变广告脸、自己加标语）。
- **电影镜头语言（2026-11-01）**：演唱特写用 85mm f/1.4 浅景深，反应镜可用过肩、插入镜用特写，开场用大远景或低角度；每镜在 `frame` 写焦段。
- **只拍手的插入镜要明写「画面里只有手和前臂，不要脸、不要头、不要其他人」**（2026-11-01〈人性之辩〉：没写，Image 2.5 在 4 张只拍手的插入镜画出整个古人，婴儿实验室还冒出两个古装男人）；**插入镜的道具不要长得像对决的人物**（布偶被画成孟子荀子Q版，等于暗示谁是坏人）。
- 小孩靠近危险（井边、月台）的画面会被 OpenAI 安全系统挡 → 改画「已经被救回来」的结果。
- **不要写「拿著东西走出画面」**（2026-11-01〈人性之辩〉F30：明朝官员捧牌位走出去，H3 让人变成残影、凭空消失，使用者一眼看出）→ 人留在画面里完成动作（例：把牌位抱在胸前低头），限制句写「stays fully in frame, never walks away, fades or blurs」。

## H3 规则（范本已写进 spec）

- 演唱镜用两人人声分轨当固定音轨（`audio.fixed`）对嘴；无声镜给静音，角色才不会自己嘟囔。
- 限制句：一镜到底、不要旗子／布条／国徽、手的结构正确、不多出人、不出现新字；擂台镜加「背景一直是擂台」、麦克风不动；`locked` 的镜加「镜头不推近」。
- **H3 会自己切镜**（常在 0.5–2.4 秒切到别的构图，有时冒红旗）：`review` 会抓；用到的范围内有切镜就加 `last_first: true`＋`seed_bump` 重拍；两次都切就改首帧（例如改成胸上近景、姿势简单）。
- 手糊掉：改慢动作、`draft: false`（14 步）、抽 2 个 seed 挑清楚的。
- **嘴不动**：首帧闭嘴又尾帧＝首帧，嘴型会被锁住；写「quietly、low voice、stays still」也会让嘴变小。先用同场已验证的首帧，action 写 `his mouth opens visibly on every syllable`、换 seed；交片前量所有演唱镜的嘴部逐格变化，抓最低的几支（2026-11-01〈瑜亮之战〉Z13）。
- **尾帧＝首帧会让插入镜几乎不动**：不需要锁的场景镜拿掉 `last_first`，用 14 步重拍，动作才看得出来；拿掉后要再查切镜与旗子。
- **摇扇子、挥道具会糊**：道具全程拿稳，动作放在头和眼神。
- **soundscape／setting 只有观众 B-roll 镜才写 crowd／cheering**（2026-11-01）：演唱镜、反应镜、DJ 镜写了人群声，H3 会把人画进背景；近景背后也不要留空旷地面。
- **慢推只准约 5%**（再多会推成大特写、改脸）；**不要用遮罩合成把背景换回首帧**（人物边缘被切到，使用者否决）。
- **每秒一格审（2026-11-01）**：背景突然冒人、糊掉、道具不连戏都要修，没修的镜头不能用。

## 字卡与特效（范本自动做）

- 片名卡、VS 卡、三人直排名牌（各出现一次）、讲白字卡（`cards`，镜头的 `gfx` 指定）、投票卡；字卡会避开脸、不压字幕和左上 ROUND 角标。
- 字幕：整句、韵脚字用己方颜色、唱到时砸下来；左下说话者色块；数字用阿拉伯数字、同音字换回原字。
- 攻击：押回去的那句从唱的人那侧射出月牙斩、对手那侧爆开（震动＋色差）；近景只在下缘角落爆开，不扫脸；COMBO「押韵！双押！三押！」、最后一句「杀招！」。
- 长演唱镜每句交替推近 1.18 倍；只在切进 `flash_scenes` 的闪回时闪白（不要每个插入镜都闪）。
- 有字卡的镜不会推近（推近会把字卡裁掉）。
