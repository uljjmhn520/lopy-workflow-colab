# 山狮霸 AI 短剧：Blender 预演与交付包

## 这技能解什么问题

AI 影片最常见的失败是**空间随机性**：座位跑掉、人物增生、背景冒出多余物件、左右换位、道具位置漂移。
社群与本专案的共同结论是**先用 3D 锁空间与运镜，再交给影片模型生成**；参考影片能约束效果，但手动做 Blender 动画太费时。

**但直接叫模型「去 Blender 做」大概率翻车——因为模型不知道表现的重点在哪。** 所以规则必须写死在这个技能里，不能靠每次临场发挥。

**界线（不可含糊）**：本法**只解空间与运镜**。它**不解决对嘴同步**。对嘴仍靠实际配音引导与最难镜头先测；**布置图通过不等于对嘴或表演通过**。

## 固定规格（本专案，不重复问）

| 项目 | 值 |
|:---|:---|
| 画面 | **16:9 横式**、**24fps** |
| 长度 | 1–2 分钟成片；本机 H3 单镜长度依台词与合法帧数，**不套 Seedance 30 秒分段** |
| 影片模型预设 | 本机 **H3 Ref2VA**（＋实际配音引导） |
| 生图 | 本机 Qwen-Image 2.1 |
| 高解析 | 原生 768p → 上下裁切 → RTX VSR 1080p |
| 运镜参考 | Blender `Workbench` 平涂色算图，不是最终风格 |

## 共同规则

- **需求先问齐再动工**：人物设定、场景、剧情走向、风格、禁则。本专案最大的时间浪费是「先批次生成才发现共通缺陷」。
- **生成之前先看画面**：每镜先算布置图，再花 GPU。布置图成本趋近于零。
- **一镜一机位要说清楚**：不同镜号若共用同一机位，要明讲，不要让镜数看起来比实际画面丰富。
- **运镜与描述不可矛盾**：标了 locked 就不写推进；想推进就必须真的做成 keyframe。这是已记录的踩坑。
- **收件要锁节点**：只取指定的 Save 节点输出，不要遍历所有输出而误收输入素材。
- **不用局部贴片救表演**：禁止旧的嘴／眼 XY 平移贴片修法；表演问题回生成端或重做必要短镜。
- **技术通过 ≠ 使用者认可**：两者分开记录；音素级对嘴未量测就照实写。

## 输出契约

**预演任务**：需求确认 → 镜表（含机位）→ 场景与布置图 →（必要时）运镜 → 检查结果。

**交付包任务**：素材清单 ＋ 提示词 ＋ 逐镜参数 ＋ 已知限制。打包到该片的交付资料夹，并保留可重跑的设定。

**绝不**：自行改动既有交付版本、覆写别人正在用的档案、或把未验收的结果写成已通过。
