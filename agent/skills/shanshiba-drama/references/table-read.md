# 生成前试映：16 宫格分镜草图＋文字读本

> 目的：在首帧与 H3 之前，先让使用者**看到故事、跟著字幕读一遍节奏**，抓出「节奏太快」「转折没交代」「片长超标」。
> **2026-10-23 起读本只给文字、不先做 TTS**：台词之后由 H3 拿角色参考音自己念（`docs/02` §6），读本声音用不到成片里；片长与每镜 H3 长度改用字数估。要先「听」一遍才做 TTS 读本（第 5 节）。
> 试映素材只给使用者内部看，不上片。档案放 `<片资料夹>/preview/`：`shots.json`、`storyboard_<k>.png`、`storyboard_<k>_label.png`、`读本_timeline.json`、`读本试映.mp4`。
> 原频道实测：一支 27 镜的 Shorts，草图约 3 分钟、组成试映影片 1 分钟；使用者看完把 99.7 秒删到 88.6 秒才进首帧。

## 0. 先把镜表写成 `preview/shots.json`

两支工具共用同一份档案（栏位说明也在两支工具的开头）：

```json
{
  "cast": "Characters (keep consistent across panels): TEACHER = ...; KID = ...",
  "shots": [
    {"id": "S01", "sec": 3, "panel": "extreme close-up: a boy thrusts a phone at the camera",
     "lines": [{"text": "老师！台风转过来了！", "caption": "阿福：老师！台风转过来了！"}]},
    {"id": "S02", "sec": 2.5, "panel": "the whole class jumps up cheering",
     "lines": [{"caption": "（全班欢呼）喔——！"}]}
  ],
  "end_card": "你的频道名"
}
```

- `panel`：给草图用的一句英文画面描述（谁、在哪、做什么、景别）。
- `lines`：`text`＝角色要念的字（不含说话者，之后 H3 spec 的台词一字不差照抄）；`caption`＝试映画面的字幕。群众声、音效、字卡说明只写 `caption`。
- `sec`：镜表秒数。

## 1. 16 宫格分镜草图（`tools/make_storyboard.py`）

```
python tools/make_storyboard.py <片资料夹>/preview/shots.json
```

- 每 16 镜一张 4×4（27 镜就是 2 张），多张同时生成。用 `tools/img25.py`（OpenAI Image 2.5，要 `OPENAI_API_KEY`）。没有金钥就跳过草图，第 2 步的试映影片会只有字幕（片长估法不变）。
- 提示词是「铅笔草图＋淡水彩、每格一镜」，**不叫模型在格子里写字**（会写错）；画好后用 PIL 在每格左上角叠镜号。
- **不附角色参考图**——只看故事顺序与构图，不验角色像不像。交给使用者时要说明「这是看节奏用的草图，不是首帧」。

## 2. 组成文字读本试映（`tools/assemble_read.py`）

```
python tools/assemble_read.py <片资料夹>/preview/shots.json
```

- 照镜表排时间轴 → `读本试映.mp4`（720×1280，草图一格一格切换、下方是字幕；**静音**，每句照一般语速每秒 4 字停留）＋`读本_timeline.json`（每镜起讫秒数、台词字数 `chars`、建议 H3 镜长 `h3_sec`）。
- **H3 镜长用 `h3_sec`**＝max(3 秒, 镜表秒数, 台词字数 ÷ 3＋2 秒)，取到 0.5 秒；字数＝中文字＋英数字，不含标点。
  - 依据（原频道〈台风假作业包〉）：H3 用参考音自己念，每秒约 2.3–4.7 字，而且 14 句里有 5 句晚 1.5–2.1 秒才开口；用这个公式，开口时间可靠的 7 句全部在镜头内念完（最紧的 13 字句算出 6.3 秒、实际念到 6.16 秒）。
  - 估长一点没关系：剪接时照 H3 实际开口时间裁掉空白，只是多花一点生成时间。`h3_sec` 超过 12 秒的镜要拆。
- 回报：**估计总长 vs 目标**、最长的三镜、超出镜表秒数的镜、要拆的镜。

## 3. 给使用者的试映包

- 试映影片＋草图＋一张表（镜号／估计秒数／台词），标出你自己觉得可能太快、没讲白的地方，请使用者看的时候特别注意。
- 说明：这是文字读本，没有声音；语气、停顿等成片出来再看，念错的句子那时再修。
- 超长就**删台词或并镜**，不要加速。使用者说「通过」才进首帧。

## 4. 之后的声音流程（H3 阶段）

- 每个角色一份参考音（你有权使用的真人录音，10–20 秒、干净、平常讲话语气），定了就不换。角色要吼、喊口令的戏，**另录一份凶的参考音**（平常语气的参考音念凶的口令会偏温和）。
- H3 spec 写 `audio.voice_ref`；两三人对话同镜就写 `audio.voice_refs`（各给参考音，最多 3 位）；镜长用 `h3_sec`。
- 跑完听写比对原文 → 念错／改用词的换 seed 再抽 2 次 → 还是错：**请配音的人录那一句**，当固定音轨（`audio.fixed`）给 H3 对嘴、只重跑那一镜；没人能录才用 BreezyVoice 固定音轨（`tools/make_breezyvoice.cmd`，这时才需要第 5 节的读音修法）。
- 写剧本时就避开 H3 容易改掉的说法（例：「二十四号」会被念成「二十四日」）。

## 5. （选用）TTS 读本：使用者要先「听」一遍时才做

- 每句台词一个 job，用该角色**定稿参考音**（`ref_audio`＋`ref_text`），每句 2–3 个 seed 就好：`tools/make_breezyvoice.cmd jobs.json`（格式见 `tools/breezyvoice_batch.py` 开头）。有装 Breeze TTS 2 也可用 `tools/breeze_batch.py`（**产出不可营利**，读本只内部听没关系）。
- 把挑中的音档写进 shots.json 的 `"wav"`（相对 shots.json），再跑同一支 `assemble_read.py`：有 `wav` 的句子照实际音长排、试映影片有声音。
- **念错的字要修**（读本是使用者第一次听到台词，念错会被当成剧本问题）：
  - 例：Breeze 会把「台风」的「台」念成四声（像「泰」）→ 配音输入写「**抬**风」（字幕照原字）。「防灾」被念成「放发」→ 输入「防**栽**」。
  - 听写（ASR）只验字、不验声调：关键字要量音高曲线（`tools/pron_check.py`），二声要「从低处上扬」，判 unsure 就当不合格。
  - 修过的读音记进你自己的读音修正表，下一支片先查。
- 配音工具若用名称快取（同名候选会跳过），换了输入文字要**换 job 名称**，不然拿到的还是旧音档。
