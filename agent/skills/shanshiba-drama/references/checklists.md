# 短剧审阅与修改清单

> **使用者叫修过的问题，都是下次自审的标准（使用者 2026-11-02）**：修完当下补进这份清单，交片前逐条过。

## 输出格式

每个问题固定四段，依**影响程度**排序：

1. **问题**：具体指出失效之处。
   - **依据**：对应的场次、镜号、节拍或台词。
   - **影响**：为何妨碍理解、情绪或节奏。
   - **修改**：可执行的修正方向。

最后列「**建议保留**」——只列真正有效、修改时应该保住的元素。

## 题材、主题与观众

- [ ] 有一句**主题锚点**，每场都能回扣。
- [ ] 一般观众（或系列指定观众）不需要背景知识；需要的背景在前 15 秒用字卡／一句旁白交代。
- [ ] 第一个画面就是钩子（0–3 秒）。
- [ ] **入戏表**：人物、场景、故事各有「观众熟悉的」＋「哪里不对劲」；有一句具体的「这就是我」（目标观众真的遇过的情境）。
- [ ] 0–3 秒有看得懂的冲突＋一个观众会想问的问题；**冲突要快、答案要慢**（答案不在开头）。
- [ ] **前 3 秒静音测试**：只看第一、二格（不看字幕、不听声音）说得出谁、在哪、哪里不对劲。

## 结构、预期曲线与情绪流

- [ ] 有钩子、推进、反转、收尾，秒数对得上目标长度。
- [ ] 节拍表的「观众此刻以为」栏每格都填了；**每个转折都写得出被哪句台词或哪个画面翻掉**。
- [ ] 相邻节拍情绪不同；全片有一个明确转调点。
- [ ] 没有重复或停滞段落；但转折后有一拍反应，不是一路冲到底。

## 角色

- [ ] 既有角色符合人设（照你的角色设定档；系列角色照 `系列设定.md`）。
- [ ] 有成长弧的角色写了 Want／Need／Lie／Flaw／Ghost，结尾回应「Lie 动摇了没」。
- [ ] 角色转变有可见行动与代价支撑。
- [ ] 有台词的新角色数量克制。

## 场次与因果链

- [ ] 每场有目标与阻力，并改变一件事。
- [ ] 场与场之间是「因为…所以」；**没有只能写成「然后」的接缝**。

## 台词

- [ ] 台词推进冲突或关系；转折与隐喻有一句讲白。
- [ ] 山狮霸台词够短；梗一听就懂，没有冷门双关。
- [ ] **台词和前后画面对得上**：提到的动作先演出来、数量一致、「他／她」指谁清楚、反应紧接动作。
- [ ] 时代细节对（例：〈AI研习宇宙〉2022–2023 没有 B5 生成式 AI 课程）。
- [ ] TTS 用字查过读音修正表。
- [ ] **文言破音字**：先查教育部辞典，**整句查不到要再查单字条目的书证**（使用者 2026-11-03，「吾与点也」整句没收，「与」ㄩˇ 的书证就引这句）；都没标音才列给使用者定，定了补进读音修正表。听写只验字、验不出声调，关键字另量 F0 或请人听。
- [ ] **片中给的具体做法要有依据**：时段、窗口这类内容法规没写就不编成像真的；先列出这个情境实际会发生什么事，答案要对题；提问的角色要得到答案、要有反应，答案要有人讲出来。
- [ ] **题材有相关新闻就先查**：写剧本前搜最新政策与新闻，官方用语照引原话；哪些是戏剧夸张写在说明栏，上片前再查一次。
- [ ] **全图闪烁**：H3 的 Veda 不开（会让整个画面在第 51／119／187 格闪一下）；拍完跑 `tools/flashcheck.py --clips <资料夹>`，0 闪才能交。
- [ ] **整片听写的 ⚠ 句子要逐句回单镜判断**：整片听写常把前后镜的声音并进来或漏掉短句；每句 ⚠ 都对单镜重听写（加逐字时间），关键字再看声调（F0），自审报告逐句写结论（修了／不用修＋理由／要人听）。
- [ ] **混音两项**：①原声关掉（gain 0）的镜是数位全静，要垫同场底噪（`roomtone`）；②没台词的笑声、掌声镜不可比台词大声（`gain` 约 0.45＋`afade` 淡出）。
- [ ] **同一镜听到两个声音**：逐镜听有没有叠音、回音、第二个人跟著念；限制句的性别要跟说话的人一致。听写看不出来，要听或看频谱。
- [ ] **新配角的参考音要先给使用者听过才拍**：`voice_profile.json` 写「待使用者听」的，交片前一定要问。
- [ ] **笑声、叹气也要用角色参考音**：没台词但会出声的镜，写一句「呵呵」之类挂 `voice_ref`，字幕给空字串；不要让 H3 自己配一个陌生人的笑声。
- [ ] **只在听的人嘴不能动**：H3 会让脸部特写的人自己讲话；只听不说的镜一律给 `audio.fixed` 静音档，嘴才会闭著。
- [ ] **道具连戏：讲电话的整段每一镜都要拿著电话**：通话中每一镜的首帧都要画电话在耳边，直到挂掉。
- [ ] **同场发型、帽子逐镜比对**：首帧提示词不要写「hair loose」这种会改发型的字；同场每张首帧并排看一次。
- [ ] **同一句里不要连用两次否定词，也不要出现相邻重字（例如「没有有」）**：观众会听成念了两次。写台词时念一遍，听起来像口吃的就改写。
- [ ] **背对镜头的镜要查左右手**：从背后拍时模型常把左手画成右手（拇指方向反了）。不演戏的那只手藏进袖子／口袋，首帧写明只看得到哪一只手，抽格时放大看手。
- [ ] **换了某一镜的版本后，字幕时间要重算**：沿用旧版的开口时间，烧入字幕会提早出现或提早消失。交片前逐镜比对字幕时间和实际开口时间（音量 > −30 dB），差 > 0.6 秒就修。
- [ ] **成片每秒一格审**（`tools/framecheck.py`）：背景突然冒人、脸或手糊掉、道具不连戏、墙上冒旗子都要修，没修的镜头不能用。
- [ ] **H3 自己切镜会切到挂旗子的教室**（2026-11-06 补）：没台词的短反应镜最常发生，常切到墙上挂旗子、贴红色标语的教室。限制句加「no flags, banners or national emblems」；用 `tools/clipcheck.py` 抓（跟首帧相关系数 < 0.7 要看）；台词讲完才切就剪掉，否则尾帧锁首帧重抽。
- [ ] **soundscape／setting 不写人群**（2026-11-06 补）：crowd、chatter、murmuring、students 这类字会让 H3 把人画进背景，锁尾帧也挡不住。
- [ ] **称呼后面的逗号会停约 1 秒**（2026-11-06 补）：H3 念「老师，」常在逗号停一下。要连著念就把 H3 输入的逗号拿掉，字幕再补回去。
- [ ] **台词开头不要放「……」**（2026-11-06 补）：H3 会在那段空白念乱语。要停顿就改「嗯，」，动作写嘴巴闭著（lips closed）的停顿。
- [ ] **背景没人的镜，动作句不要写「背景的人保持小动作」**：旧的通用动作句会把人叫进背景；背后改成墙或门塞满。
- [ ] **走路、移动镜用 14 步、正常步速**：快走会让腿和袍子糊掉；不是重点就别写 fast。
- [ ] **连续讲话的跳切**：同一人、同构图接连两镜，后一镜用 `punch` 放大 20%（以脸为中心）；画面本来就很紧、放大会切到头的，才换镜位重拍。`review_ep.py` ④d 会列出。
- [ ] **montage／主题曲段落把 H3 原声关掉**：H3 会自己生含糊的人声。
- [ ] **配乐不要在两句之间弹回来**：空档不到 1 秒时，配乐压低后放开又压，会变成「噗」一声；`assemble_ep.py` 已把短空档一起压住。接点音量跳 >20 dB 要量是原声还是配乐。
- [ ] **时间跳跃字卡（〈十年后〉）要大、置中**：预设 64 号字太小，用 120 号。
- [ ] **片中引用的经典、成语、真实事件，自己要能讲出处**：出处写在剧本的实际案例表，上架时放说明栏。

- [ ] **双语片先列每个角色讲哪种语言（〈One Minute with Mina〉使用者：「在脚本里面，学生是说英文，不是说韩文」）**：写镜表前列一张「角色—语言—讲几次」的表给使用者确认，不要把「所有对话」套到每个角色。

- [ ] **特写的 setting 不写大场面（〈Make Our Own Light〉自审）**：setting 写「巨型舞台」时，6 个特写镜两个 seed 都被 H3 拉成远景、冒伴舞、换衣服、冒旗子。特写 setting 只写眼前失焦的背景，限制句写不准拉远、舞台地板与伴舞不出现，重拍 7 镜全部稳住。

## 反转与收尾

- [ ] **翻盘用的关键词（身分、名称、真相）在翻盘前没有出现**（字幕、面板、道具字、内心都算）；开场用模糊说法代替（使用者 2026-10-15，〈AI研习宇宙〉Ep6「一开始就说承办，爆了后面的梗」）。

- [ ] 9:16：多人用纵深、上下错开；字卡在上半部且不挡脸、避开 Shorts 说明区。
- [ ] 16:9（指定时）：有用到宽景，特写克制。

- [ ] **手要连到肩膀（使用者 2026-11-04，第 7 集 v2）**：逐镜看手不只数手指，也要看肩膀→袖子→前臂→手是不是同一只手、手是不是从人在的那一侧进画面；袖子不能跟手分开垂著。
- [ ] **剧中职务查实际归属（使用者 2026-11-04，第 7 集 v2）**：每项工作、每个职称都查过通常归哪个单位（学校用处务规程、职掌表），不存在的职称不用；不是主角的工作要讲白为什么落到他头上。
- [ ] **画面上要读的字要念出来（使用者 2026-11-03，第 6 集 v1）**：单子、字卡、手机讯息、古文，超过约 8 个字（书名出处不算）就要有人念，**镜长跟念的长度一致**，不要让观众自己看；自审工具 第 ⑦ 项会列出没人念的长字卡。
- [ ] **真实案例不能只讲结论（使用者 2026-11-03：「绕路载上学，刁难请假，这是什么意思，我看不懂」）**：投诉、新闻、规定的句子，要让第一次听的人知道前因（谁要做什么、老师做了什么）才接结论；需要时拆成「前因—角色回应—结论」三镜。
- [ ] **没台词的镜，背景不准自己冒人声（使用者 2026-11-03）**：soundscape 不写任何人的说话、念书声（H3 会生出来路不明的声音）；剧情要有谁的声音，就拍那个角色念，只取声音叠上去（`cut_config.vo`）。
- [ ] **破音与多音字要看片中整句（使用者 2026-11-03：排挤的「挤」念错，听写抓不到）**：听写对不代表声调对；句尾关键字量音高，再查读音修正表。
- [ ] **听写只差一个字也要看（使用者 2026-11-03：「载」念成「宰」，相似度 0.84 过了门槛）**：听写结果跟字幕逐字比对，不同的字逐条判断，同音字放过、破音字念错就重抽；自审有怀疑的字，交片讯息一定要列出来。
- [ ] **声音和画面不能累积偏移（2026-11-04）**：修剪到镜尾时来源可能少 1 格，每少 1 格后面全部错开。剪接工具要补足缺格并比对总格数；字幕挂到下一镜就是征兆。
- [ ] **背景有门口、空地就会冒人，锁尾帧也挡不住（2026-11-04）**：连 3 个 seed 都冒就改首帧，背景只留墙。
- [ ] **画外念白也要听写（使用者 2026-11-03：1:44「欲」念成「又」，念白不在整片听写表里，自审没查到）**：画外念白的声音来源也要逐字比对、逐条判断；同一个字在别镜念对，不代表这镜也对。

- [ ] **动作不能卡住**（〈人不知〉MV 使用者：「3 秒，动作卡住」）：首帧画在跨步中间，H3 只会定在那个姿势晃。走路镜首帧画站定、双脚并拢，action 逐步写步数；交片前看脚有没有真的交替（光流检查抓不到这种）。
- [ ] **身体和脖子要合人体工学**（〈人不知〉MV 使用者：「身体脖子违反人体功学」）：不要背对镜头却把头转过肩膀。要回头的镜，首帧全身侧面，action 写脚、腰、肩、头一起转；首帧就检查头和肩的夹角不超过约 90 度。
- [ ] **画面意象要说得通**（〈人不知〉MV 使用者：整栋楼窗户一格格亮「不合理」）：比喻镜也要过「现实里为什么会这样」。夜里空教室整栋亮灯说不通；要讲「大家都还亮著灯」，就拍每个人各自在灯下做事，全景只留零星自然亮著的窗。

- [ ] **手机、相机方向要对**（〈人不知〉MV 使用者：「学生手机拿反了」）：拍摄的人，镜头朝被拍者、萤幕朝自己。首帧写清楚，最好从拍摄者身后拍，让萤幕朝镜头、萤幕里看得到被拍者；光写 back of the phone toward the camera 会反。
- [ ] **作揖、握手这类手部特写要避开**（〈人不知〉MV 使用者：「孔子握拳的手怪怪的」）：写 clasped hands 会画成拳头顶在胸前。古装行礼把双手收进并拢的袖子里，首帧就看不到手指。

- [ ] **转身不能换脸**（〈人不知〉MV 使用者：「2:38 人脸跑掉」）：首帧是侧面、片中才转正脸，一定锁尾帧（Image 2.5 另做正面完成姿势）；首帧尽量看得到两只眼睛。审片要比首尾两格是不是同一人。
- [ ] **窗内、房间深处会冒人**（〈人不知〉MV 自审）：窗内拍人身后留房间，连续三次有人走过；身后贴拉上的窗帘才干净。静态空景拍超过 4 秒也可能自己跳别的场景，逐镜看。
- [ ] **闭口音长音不硬拍对嘴**（〈人不知〉MV 自审）：「灯」这类字 H3 会闭著嘴唱；唱到那个字就切到歌词讲的画面。
- [ ] **进片尾要有铺陈**（〈人不知〉MV 使用者：「最后接结尾画面太突然，不顺」）：最后一句台词后留一拍，音乐先淡入铺垫，画面用溶接；结尾画面也要溶进去，字慢慢出来、跟音乐一起收。
- [ ] **试听要放到会被影响的段落**（〈人不知〉MV 使用者：重唱版「副歌跟上一版不太一样，上一版比较好听」）：我只放接点前后 25 秒，连续重唱版后面整段都换了，使用者选的时候根本没听到副歌。比方案时，每个方案会改到的段落都要放进试听。
- [ ] **换画面时音乐不要跟著断**（〈人不知〉MV 使用者：「结尾音乐过去太不顺，你接画面的话，音乐不用硬切」）：不要歌收成静音、口白干讲、再淡入下一段。伴奏压低垫在口白底下，接到下一段时不断；量每秒响度，低于约 −40 dB 超过 1 秒就算断。
