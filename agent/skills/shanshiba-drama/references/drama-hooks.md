# AI 短片抓马梗：上位模式整理（2026-10-11）

> 使用者要求：找 AI 短片（含 AI 短剧、AI 猫狗剧、brainrot、微短剧）里常用的「抓马」点，**抽成上位概念，可以套到任何主题**。第一个要套的是〈AI研习宇宙〉。
> 来源：微短剧编剧方法文（知乎、搜狐、人人都是产品经理、远见）、AI 猫狗短剧产业分析（21 世纪经济报导）、海外 microdrama 分析（Rappler、BuzzFeed）、AI 影片趋势整理（Versely 等）。**多为业界经验分享，不是学术定论**；下面的分类是整理后的归纳。

---

## 一、所有抓马的共同引擎（四种「差」）

每一个爆款梗，拆到最底层都是制造落差：

| 引擎 | 意思 | 观众的感受 |
|:--|:--|:--|
| **地位差** | 谁压谁，然后上下颠倒 | 憋屈 → 爽 |
| **资讯差** | 有人知道、有人不知道（观众常常先知道） | 紧张、等著看好戏 |
| **身分差** | 看起来是 A，其实是 B | 震惊、「原来如此」 |
| **形象差** | 外表和行为不搭（可爱的脸讲狠话） | 好笑、上头 |

**情绪公式：先压（委屈、羞辱、被看不起）→ 再爆（反转、打脸、揭露）→ 不给满足就切断（卡点）。**
微短剧业界叫「爽点」：观众在那一刻得到的情绪回报；「情绪价值」与「多巴胺」被当成流量核心。

## 二、20 个上位抓马模式（可套任何主题）

> 每个模式都写：**骨架**（抽象写法）／**短剧常见样子**／**换成任何主题的套法**。

### A. 身分与地位类

**1. 隐藏身分（扮猪吃老虎）**
- 骨架：最不起眼的人，其实是最高层级的那个。
- 短剧：亿万富翁装穷、被嫌弃的女婿其实是大佬、实习生其实是董事长。
- 套法：找出这个主题里「最被看不起的角色」和「最高的头衔」，把两个叠在同一个人身上。

**2. 身分揭露的那一刻（掉马甲）**
- 骨架：一句话、一张卡、一个动作，让全场知道他是谁。
- 短剧：「总裁突然出现喊她老板」、亮出证件、一通电话「董事长您好」。
- 套法：设计一个**可视化的身分证明**（名牌、证书、徽章、一句称呼），在最低点亮出来。

**3. 地位颠倒（跪下梗）**
- 骨架：前半段 A 逼 B 低头，后半段 A 对 B 低头。
- 短剧：反派要主角跪下，身分曝光后反派自己跪地求饶。
- 套法：同一个动作做两次，**施受者对调**（前面谁要谁道歉、后面就换人道歉）。

**4. 一句话摆架子（你知道我是谁吗）**
- 骨架：配角用头衔压人，主角轻描淡写回一句，头衔瞬间失效。
- 套法：让配角炫耀一个这个领域的「等级名称」，主角的等级刚好高一阶或完全不同维度。

**5. 被抛弃 → 对方后悔（退婚／火葬场）**
- 骨架：一开始被拒绝、被开除、被刷掉，之后对方发现错过了宝。
- 短剧：退婚、被赶出家门、被公司开除，三年后回来。
- 套法：「当初谁没选你」+「现在你成了他要求的人」。

**6. 团宠／一群大佬撑腰**
- 骨架：主角一出事，好几个强者同时出场护他。
- 短剧：「五个大佬哥哥」、各路高手都是主角的人。
- 套法：把这个主题里的各种「派系代表」都变成主角的靠山，同时现身。

### B. 资讯与真相类

**7. 观众先知道（资讯差）**
- 骨架：观众知道秘密，角色不知道，等著看他怎么踩雷。
- 业界说法：卡点前先制造「观众知道、角色不知道」的落差最有效。
- 套法：开头就让观众看到真相，接著让角色在不知情的状况下讲出会被打脸的话。

**8. 当众公审（拿出证据）**
- 骨架：在最多人看的场合，摊出一个无法反驳的证据。
- 短剧：宴会、婚礼、董事会、家族聚餐；甩出录音、合约、DNA。
- 套法：选这个主题里**最公开的场合**（会议、典礼、群组）＋**最有公信力的文件**。

**9. 真假错认（真假千金）**
- 骨架：两个人身分被调包，错的那个享受一切，对的那个被嫌弃。
- 近年流行**反套路**：真千金不吵不闹、自己变强，反而是另一种打脸。
- 套法：两个看起来很像的东西／人，被大家认错；揭晓时所有人的态度瞬间翻面。

**10. 背叛与偏心**
- 骨架：最亲近的人站错边。
- 短剧：丈夫外遇闺蜜、父母偏心、绿茶表面无辜。
- 套法：主角的「自己人」在关键时刻选择了对手（之后一定要回收：后悔或被揭穿）。

### C. 规则外挂类

**11. 重来一次（重生／回到过去）**
- 骨架：带著未来的记忆，回到出事前的那一刻。
- 套法：「如果我早知道……」→ 让主角回到某个关键日子，每个选择都做对，旁人看不懂。

**12. 系统／面板（外挂）**
- 骨架：主角突然看得到别人看不到的规则、数值、任务提示。
- 短剧：「叮！系统启动」「完成任务奖励○○」。
- 套法：把这个主题里**真实存在的数字**（分数、时数、等级、KPI）变成只有主角看得到的游戏面板。

**13. 倒数与限时赌注**
- 骨架：有个时间或数量的期限，不达成就完蛋。
- 套法：用这个主题里真的有的期限（截止日、考试、评鉴）做倒数字卡。

**14. 夸张数字**
- 骨架：数字大到不合理，用来一秒建立赌注。
- 短剧：亿元支票甩脸、十倍奉还、千万违约金。
- 套法：把这个主题的小数字放大成史诗级（「一百小时」「全国第一」）。

### D. 形象反差类（AI 短片特别吃这套）

**15. 可爱外表 × 成人剧情（拟人反差）**
- AI 猫狗剧：猫扮贵妃甩小宫女巴掌、讲宫斗台词；柯基演美剧；胖橘系列连载百集。
- 骨架：用最萌、最无害的外型，演最狗血、最权谋的戏。
- 套法：选这个主题里**最不像会吵架的角色**，让他们上演宫斗。

**16. 错置场景（动物上班）**
- AI 猫狗剧：猫送外卖、挤地铁、打工。
- 骨架：把角色丢进不属于他的场景，照样认真做事。
- 套法：把 A 领域的人放进 B 领域的规则里（例：用武侠的方式开会）。

**17. 荒谬混种（brainrot）**
- 例：义大利 brainrot（咖啡杯头的芭蕾舞者）、水果出轨剧（fruit slop）。
- 骨架：两个不该结合的东西硬结合，再认真给它一个身世和剧情。
- 套法：把这个主题的两个名词拼成一个角色，并给他一句招牌台词。

**18. 是真的吗？（double take）**
- 例：AI 假街访、像真的但有一点怪。
- 骨架：一开始看起来完全正常，细节越看越不对。
- 套法：先拍得很写实，再慢慢放一个「只有仔细看才发现」的破绽（**我们频道〈拿下头套的人〉已经用过 AI 穿帮梗**）。

### E. 结构与收尾类

**19. 戛然而止（卡点）**
- 骨架：在揭晓的前一格切黑，而不是在解决之后。
- 业界：卡点要落在主线、停在「即将爆发」的瞬间；要具体到某一句台词或动作，不能只写「留下悬念」。
- 海外分析（Rappler）：microdrama 等于**把悬念变成收费点**——反派要垮台、女主亮出证据的那一秒，画面变黑。

**20. 反套路（观众以为会这样，结果再翻一层）**
- 骨架：先照套路走，让观众猜到下一步，然后拒绝给那一步。
- 套法：用前 19 招其中一招铺好，最后一秒改走另一招。

## 三、节奏公式（短片长度通用）

| 时间 | 要做的事 |
|:--|:--|
| **0–3 秒** | 冲突或反常画面直接出场（被羞辱、东西被甩到脸上、奇怪的组合） |
| **3–10 秒** | 交代人物关系：谁压谁、赌注是什么 |
| **中段** | 主角受压，情绪累积（委屈越深，后面越爽） |
| **中后段** | 反转：身分、实力或真相揭露 |
| **结尾** | 爽点爆发 → **立刻丢一个新问题**（下一集的钩子） |

- 业界经验值：每 30 秒一个钩子；每 2 分钟至少一个。
- 连续剧：小反转每 5–10 集、大反转每 20–30 集；第一个付费点约第 8–12 集。
- 单集只推进**一件事**。

## 四、AI 短片常见的视听语言（拍法）

- **甩东西到脸上**（文件、支票、考卷）＝冲突开场的标准画面。
- **全场倒抽一口气**：一排人同时转头、张嘴、杯子掉地。
- **镜头推近眼神**＋眼神由卑微变冷：「她不装了」的瞬间。
- **身分字卡**：人物定格＋大字头衔（我们频道的**咒印名片**就是这招）。
- **慢动作走进来**：靠山登场。
- **悲伤流行歌**配上动物或物品的剧情（海外 AI 猫剧常用）。
- **跪地、鞠躬、手抖的特写**：地位反转的画面证据。
- **切黑＋「未完待续」**：卡点。

## 五、套用检查表（写任何主题前先问）

1. 这个主题里，**谁最被看不起？谁的头衔最高？**（→ 隐藏身分）
2. 这个主题有哪些**等级、证书、称号、数字**？（→ 掉马甲道具、系统面板、夸张数字）
3. **最公开的场合**是哪里？（→ 当众公审）
4. 有没有**两样容易被搞混**的东西？（→ 真假错认）
5. 有没有一个**真实的期限**？（→ 倒数）
6. 谁是**最不像会吵架**的角色？（→ 萌外表演宫斗）
7. 开头 3 秒的**反常画面**是什么？
8. 最后一秒停在**哪一句台词**？

## 六、先试套〈AI研习宇宙〉（只是示范，剧本另写）

| 模式 | 研习宇宙版本 |
|:--|:--|
| 隐藏身分 | 坐最后一排滑手机、被讲师点名的老师，其实是 Google 认证训练讲师／梦N 总召 |
| 掉马甲 | 签到表上的头衔一栏写著「教育部 B5-1 讲师」，全场安静 |
| 地位颠倒 | 上半场讲师逼大家贴便利贴；下半场讲师要请这位老师帮他开投影机 |
| 你知道我是谁吗 | 「我是 AI 酷课师！」→「喔，我是酷课师的讲师的讲师。」 |
| 被抛弃→后悔 | 当年被梦N研习刷掉的老师，三年后成了那一区的总召 |
| 团宠 | 主角被刁难时，Apple、Google、微软、优派四大阵营的认证讲师同时走进来 |
| 系统面板 | 主角眼前浮现「研习时数 17.5／18」「A3 完成率 60%」 |
| 重生 | 回到 A1 研习那一天，这次他坐第一排 |
| 倒数 | 「研习时数登录截止：倒数 3 天」 |
| 萌外表演宫斗 | 三家书商的吉祥物在科技展抢老师 |
| 荒谬混种 | 「平板车」成精，五个班抢它 |
| 卡点 | 「本研习时数将核予——」切黑 |
