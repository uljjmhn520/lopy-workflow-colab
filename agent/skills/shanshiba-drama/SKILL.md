# AI 短剧编剧

> **本 repo 版本说明（2026-10-23 更新，优先于 references 里的旧说法）**
> - 角色是**你自己的角色**：references 提到的「山狮霸」「阿福」「〈AI研习宇宙〉」是原频道的例子，本 repo 没附角色资产。请先照 `docs/07_本地角色与首帧.md` 做好角色定妆照与参考音，把每个角色的外观描述（年龄、脸、发型、眼镜、上衣与下半身）写进你专案的角色设定档，剧本与提示词都引用它。
> - 影片模型是**本机 MiniMax H3**（每镜 ≤12 秒）；制作流程看 `docs/02_端到端流程.md`，技术限制看 `docs/03_规则与踩坑.md`。
> - 首帧：原频道用 OpenAI Image 2.5（`tools/img25.py`）；全本地做法见 `docs/07_本地角色与首帧.md`。

## 开工前必读（不可跳过）

1. 你专案的角色设定档（外观、声音、表情）。角色外型一律**引用设定档**，不在剧本里自己重写。
2. 抓马与节奏：`references/drama-hooks.md`（四种差、20 个模式、0–3 秒节奏）；**入戏条件**：`references/audience-entry.md`（熟悉的人物／场景／故事＋各自一个意外、「这就是我」、冲突要快答案要慢、前 3 秒静音测试）。
3. **系列作**：该系列的 `系列设定.md`（＝系列圣经）与 `制作规则_累积.md`。每集照做，交付后把新规则补进累积档。
4. 专案 `CLAUDE.md` 的通用规则与 `docs/03_规则与踩坑.md`。

## 固定规格

| 项目 | 值 |
|:---|:---|
| 画面比例 | **预设 9:16 直式（YouTube Shorts）**；使用者指定才做 16:9 横式。两种都要重新生成，**不裁切** |
| 长度 | 1–3 分钟（Shorts 上限 3 分钟；H3 每镜多出的空白要修剪） |
| 镜头 | 首帧 → 本机 H3；**每镜 ≤12 秒**（超过容易自己切镜、漂移）；没台词的过场镜约 3 秒内 |
| 帧率 | 24 fps |
| 配音 | 画面内角色台词**预设 H3 自己念＋角色参考音**（spec `audio.voice_ref`；两三人对话可同镜：`audio.voice_refs` 各给参考音，最多 3 位）；参考音用真人录（要吼的戏另录凶的参考音）；**念错再修**：换 seed 抽 2 次 → 请人录那一句当固定音轨 → 没人能录、数字日期难字、精准声画同步才用 BreezyVoice（`tools/make_breezyvoice.cmd`）固定音轨。读本试映只给文字、用字数估镜长（`references/table-read.md`）。台词避免单一个字（「考。」「接！」改成两三个字） |
| 观众 | **一般人**（系列另有指定就照系列）：每个转折、隐喻都要有一句台词／旁白或一个画面讲白 |

## 判断任务

- **完整一支／一集**：读 `references/workflow.md`，九个阶段＋生成前试映，**每阶段过关卡**（列 3–5 条自检、等使用者「通过／修改」）才往下。使用者说「一次做完」才跳过关卡，但自检照做。
- **单点创作**（只要题材／结构／某一场／台词／反转）：读 `references/workflow.md` 对应阶段，**只交付指定成果**。
- **写剧本或要格式**：读 `references/format.md`。
- **排镜表**（剧本已存在）：读 `references/segmentation.md`。
- **生成前试映**：读 `references/table-read.md`（`tools/make_storyboard.py`＋`tools/assemble_read.py`）。
- **审阅或修改**：读 `references/checklists.md`。

## 共同规则

- 只询问会实质改变结果的缺漏；其余采合理假设并**清楚标示**。
- 保留使用者指定的长度、类型、观众、场景与交付形式。
- 写**现在正在发生的可见行动**；动作要夸张一点、分镜多一点（反应镜、插入镜、推近、汗珠特写、全场同步转头）。转成 H3 spec 时，`action` 照官方 `h3-prompt-writing` 技能写 50–120 字的具体动作过程，动作镜首帧画「动作开始前」的姿势（见 `references/segmentation.md`）。
- 每场至少改变资讯、关系、目标、风险或情绪之一；场与场之间是「因为…所以」，不是「然后」。
- 反转必须能由前文线索回看成立，而且**被哪一句台词或哪一个画面翻掉要写得出来**。
- **台词和前后画面要对得上**：台词提到的动作先演出来、数量一致、「他／她」指谁看得出来、反应紧接动作。
- 节奏明快但不能快到看不懂：转折后留一拍让观众消化（反应镜或一句讲白）。
- 教室戏（原频道常用）：老师不碰学生；黑板在前、学生面向黑板、窗在学生左手边；上课期间背景要有同学。
- 使用者只要剧本时，**不输出** H3 提示词、seed、步数——那是制作阶段（`tools/h3_shot.py`）的事。

## 输出契约

**创作任务**：必要假设 → 主题锚点 → 指定创作成果 →（完整一支才附）镜表与试映清单。

**审阅任务**：依影响程度排序的诊断、对应具体段落的证据、可执行的修改方向；只有能说明修正或使用者明确要求时才提供改写。
