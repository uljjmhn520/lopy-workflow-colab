# 07 本地角色与首帧（不用云端生图）

原专案的首帧是用云端的 OpenAI Image 2.5 生的。这份 repo **预设全本地**：角色定妆照、首帧全部用 Qwen 系列模型在本机生成。以下每一条都是 2026-10-07 在三种硬体配置下实测过的。

## 1. 先做角色：单张半身定妆照

用 Qwen-Image 2.1 生一张「灰底、正面、半身、只有一个人」的照片，当这个角色之后所有画面的参考。

```
C:\AI\H3\venv\Scripts\python.exe C:\AI\tools\gen_image.py --width 1024 --height 1024 --seed 11 --out chars --prompt "Studio character reference photo, single person only, one image (not a collage), medium close-up bust portrait facing the camera, plain light grey seamless background, soft even studio light, sharp focus, realistic photograph. <角色外观：年龄、脸、发型、眼镜、服装>, gentle natural expression. No text, no watermark."
```

- **只能一格**。我们试过把「三格定妆照」（全身＋半身＋脸）当参考图，Qwen 会把整张的版面照抄，生出拼贴图。
- 外观描述写具体（年龄、脸型、发型、眼镜、上衣**与下半身**的颜色款式），之后每一镜的提示词都照抄同一段。没写下半身，全身镜会随机配裙子或长裤。
- 同一个 seed 不满意就换 seed 多生几张，挑一张定案，之后不要再换。

## 2. 生首帧：两种做法

| | A. Qwen-Image-Edit 附参考图（预设） | B. Qwen-Image 2.1＋角色 LoRA |
|---|---|---|
| 要不要训练 | 不用 | 每个角色一次：产生训练图约 20 分钟＋训练（5090 模拟 16GB＋32GB 实测 33 分钟；真实 16GB 卡推估 1–1.5 小时） |
| 长相像不像 | 像 | 最像 |
| 会不会照剧本演（景别、动作、侧脸） | **会** | 会 |
| 输出 | 直接 1344×768（H3 要的尺寸） | 2K（2688×1536），细节最好，缩成 1344×768 再给 H3 |
| 多人同框 | 最多 3 张参考图（`<image1>`～`<image3>`），2 人实测可行 | 两个 LoRA 同时挂会互相稀释 → 先出构图、再用 `qwen21_face_refine.py` 逐人重绘 |
| 每张时间（5090） | 附 1 张参考图约 47 秒（16GB 卡模拟约 50–55 秒）；附 2 张（定妆照＋场景母版裁切）约 85 秒 | 约 57 秒 |

**不要用的做法**：Qwen-Image 2.1 直接附参考图（不训练）。长相会像，但每张都变成跟参考图一样的正面置中姿势，要求「侧脸看窗外」也照样正面。

### A. Qwen-Image-Edit 附参考图

```
C:\AI\H3\venv\Scripts\python.exe C:\AI\tools\gen_image.py --model qwen-edit --ref chars\yun.png --width 1344 --height 768 --seed 5101 --out first --prompt "Keep exactly the same person as <image1>: same face, hairstyle and clothes. New photo: <电影感句> <这一镜：景别、角色在哪、做什么、表情> No text, no watermark, no captions."
```
双人镜：`--ref A.png --ref B.png`，提示词写「the man from <image1> ... the girl from <image2> ... Only these two people.」

### B. LoRA

1. 产生训练图（用 A 的方法换景别、角度、表情、场景）：
   ```
   C:\AI\H3\venv\Scripts\python.exe C:\AI\tools\make_lora_dataset.py --ref chars\yun.png --trigger yun_local --desc "the girl Xiaoyun, a bright 11-year-old Taiwanese schoolgirl with a short black bob ..." --out datasets\yun
   ```
2. **逐张看，删掉脸不像、多手多脚、有字的图**（原专案每个角色都这样做）。
3. 照 `setup/lora/README.md` 用 AI Toolkit 训练（768 解析度、rank 32、1600 步）。2026-10-07 已用示范片角色「小芸」从零走完这条路（本机定妆照→本机训练图→16GB＋32GB 模拟下训练→首帧），三个场景都像本人。
4. 生首帧：`gen_image.py --lora yun_local.safetensors:1.0 --prompt "yun_local, the girl Xiaoyun, ... <这一镜>"`；提示词一定要放触发词和外观描述。

## 3. 首帧提示词的固定写法

照 `tools/examples/qwen21_prompt_template.txt`（电影感范本）：
- 开头固定：`A cinematic film still from a Taiwanese coming-of-age movie, shot on Kodak Vision3 500T film with an anamorphic 50mm lens at f/2`
- 光线要写具体（例：夕阳从窗外低角度照进来、逆光、发缘轮廓光、空气中的光束、琥珀色调色）。只写 soft daylight 会变成平淡的白光。
- 背景一句话带过、保持简洁；逐项列出房间里的东西会让画面杂乱。
- 结尾固定：`No text, no watermark`；要干净的黑板就写 `a green chalkboard with nothing written on it`。

## 3b. 真人感写法（2026-10-31 起原专案首帧预设）

网路上「让 AI 影片有真人感」的做法，原专案整理后做了 A/B 实测，**只在 OpenAI Image 2.5（云端）上测过；Qwen-Image 2.1 本机版还没测**，用在 Qwen 前请先自己对照几张。

- **真人感在首帧就决定了**：H3 用同一段提示词、同一个 seed，只换首帧，首帧的光线、肤质、背景会整支影片保留；反过来首帧不变、只在影片提示词加手持晃动、重量、眨眼等描述，肉眼看不出差别（3 个场景实测）。→ 影片提示词照官方写法，不必另外加。
- **不要写** `photorealistic, 8K, masterpiece, flawless, perfect, beautiful`：实测会变成广告脸＋金黄 HDR 光，4 张有 3 张还**自己在黑板／马克杯上加励志标语**。
- **好看但有特色，不刻意变丑**：网路常见的「加痘疤、雀斑、普通长相」会把人变老变丑；改写 3–5 个具体个人特征（眉形、痣、笑法、鬓角、胡渣），并写「看起来就是设定年龄」。疤痕要写 `faint pale old scar`，只写 scar 会画成红色新伤。
- 固定段落（接在场景描述前面）：

```
Unretouched candid photo taken on a phone by a colleague, eye level, slightly off-center framing,
ordinary everyday moment, the person is not posing for the camera.
Lighting: one real light source only as described in the scene, with matching shadow direction and soft falloff,
shadows keep detail, slight mixed white balance between daylight and indoor light.
Face: a genuinely good-looking real person, like an actor photographed off-duty with no retouching;
attractive because of distinctive individual features (described in the scene), not because of perfection,
not a generic AI beauty face. Healthy skin with natural texture and visible pores, faint natural shine,
slight natural asymmetry, a few stray hairs, real lip texture, looks exactly the stated age. No acne, no blotches, no heavy freckles.
Hands: anatomically correct hands with exactly five fingers each, visible knuckle creases, natural nails;
each hand has one clear job and fingers physically wrap around or press on the object, with contact shadows.
Clothing has real creases. The environment has small everyday clutter.
Camera: phone-camera look, natural shallow depth falloff, subtle sensor noise, no HDR, true-to-life colors.
Avoid: plastic or waxy skin, airbrushed retouching, doll-like perfect symmetry, studio glamour, advertising look,
oversaturated color, extra or fused fingers, readable text or logos.
```

- 调整：场景需要字（萤幕、招牌）→ 把 `readable text or logos` 改成 `any text other than: "<要的字>"`；已定型角色 → 长相照定妆照不改，只套光线、肤质、手、环境、相机；要电影感 → 相机段改成 50mm＋浅景深，肤质与单一光源保留。
- Image 2.5 实测：8 张的手全对（五指、比三、筷子、捧杯），静态首帧的手不是瓶颈；手部问题主要出在影片的快动作。

## 4. 场景一致

- 同一个场景的多个镜头，先生一张空场景母版，之后每一镜把母版**裁成想要的景别**再当参考图附上（附整张会照抄成大全景）。
- 不要附别支片的完成画面当「风格参考」：Qwen 会把里面的人物和物件也画进来。

## 5. 示范

`pipeline/demo_local/run_demo.py` 用做法 A 从零做出两个角色和 4 镜首帧，再一路做到成片；在「16GB 显卡＋32GB 记忆体」模拟条件下实测可完整跑完。
