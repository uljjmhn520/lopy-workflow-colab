# 06 安装

Windows 11＋NVIDIA 显卡。所有路径以 `C:\AI` 为惯例；要放别处就改各脚本顶端的路径，或设下方的环境变数。

## 1. 资料夹惯例

```
C:\AI\
  H3\            ComfyUI＋H3 主环境（venv＋ComfyUI 程式＋models）
  Voice\         语音环境（VoxCPM2、faster-whisper、stable-ts、audio-separator、edge-tts）
  BreezeTTS\     Breeze TTS 2（程式库 breeze-tts、权重 breeze-tts-2、独立 venv；只用来设计角色参考音）
  BreezyVoice\   BreezyVoice（code、model、winstub、Python 3.10 venv；所有台词配音）
  Blender\       Blender 5.x portable（预演用，选用）
  tools\         ← 把本 repo 的 tools\ 复制到这里
```

## 2. 主环境（ComfyUI＋H3）

| 项目 | 原专案版本 |
|---|---|
| Python | 3.12.14 |
| PyTorch | 2.14.0+cu130（CUDA 13.0） |
| ComfyUI | 0.37.0（资料夹名称是 `ComfyUI-0.36.0`，原地升级过）；**Colab 版自动装 0.40.0＋Veda**（2026-10-16） |
| comfy-kitchen | 0.2.35（INT8 注意力、ConvRot 量化） |
| ffmpeg | 9.0.1 full build（需要在 PATH 上，含 ffprobe） |

ComfyUI 自订节点（H3 本身是核心节点，不用装）：
- `Nvidia_RTX_Nodes_ComfyUI`（RTX VSR）、`ComfyUI-FlashVSR_Ultra_Fast`（全景放大）
- `ComfyUI-GGUF`、`ComfyUI-KJNodes`（工具）
- 选用：`ComfyUI-Fisher-Pose`（姿势）、`Comfyui_Minimax_h3_latent_Upscaler`（H3 精修）
- 选用（本 repo 自带）：`setup/comfy_nodes/whitemodel_color` → 复制到 `ComfyUI/custom_nodes/`、重启 ComfyUI。多人白模每人一个固定颜色（`make_whitemodel.py --colors red,blue`）。
- 选用（需要 ComfyUI ≥ 0.38）：`Veda-on-ComfyUI`（学习式稀疏注意力）＋`setup/downloads_veda.json` 的打分器。**预设不开**（2026-11-02）：开了整个画面会在第 51／119／187 格闪一下，同镜同 seed 关掉就没事，快约 20% 不值得；真的要开才在 spec 写 `"veda": true` 或设 `H3_VEDA=1`，开了要逐格检查亮度。

- 选用（**远景小脸精修**，`tools/face_refine.py`，2026-10-24 加入；**原频道只在 ComfyUI 0.40＋RTX 5090 实测**，0.37 缺 FaceRefine 用到的内部函式，能跑但未实测；16GB 显卡、Colab 未实测）：
  1. `ComfyUI-H3-FaceRefine`（MIT，commit `d8521d1`）clone 到 `custom_nodes/`。
  2. `ComfyUI-H3-NativeAudioLock`：只有 71 行、放在另一个 repo 的子资料夹、**没有授权档** → 本 repo 不附，请自己 clone `https://github.com/Shrek3OnVH5/MiniMax-H3-NativeAudio-MusicVideo-Workflow`（commit `11a95f6`），读过 `custom_nodes/ComfyUI-H3-NativeAudioLock/__init__.py` 再复制进 `custom_nodes/`。作用：把原片音轨锁进 H3 的 latent，重画脸时嘴型跟著原音。
  3. H3 venv 加装 `setup/env/requirements_facerefine.txt`（ultralytics、scenedetect 等；`--no-deps`，torch／numpy 不动）。注意 ultralytics 是 AGPL-3.0。
  4. 下载 `setup/downloads_facerefine.json`（FL2VA 剪枝 int8 21GB、fl2v turbo 8 步 LoRA 1.9GB、`face_yolov8m.pt` 52MB）。
  5. 重启 ComfyUI，确认 `/object_info` 有 `H3FaceTrackCrop`、`MiniMaxH3NativeAudioLock`。用法见 `docs/02_端到端流程.md` 第 7 节。

`upscale_vsr.py` 需要的 `nvidia-vfx`、`av` 已经在 `setup\env\requirements_h3_venv.txt` 里，照 AGENT_SETUP 装就有；自订节点的 requirements 不用另外装。

启动：`C:\AI\tools\start_comfy.cmd`（`--fast fp16_accumulation --cache-none`，127.0.0.1:8188）。

## 3. 模型下载

**实际指令以 `AGENT_SETUP.md` 第 3 节为准**（先 `cd <repo>\setup` 再跑 `download.py <清单>`，cmd 与 PowerShell 两种写法都有）。清单都钉了版本，每个档都会验证杂凑，支援续传；已验证过的档案会自动跳过。下面补充 AGENT_SETUP 没列的选用清单：

| 清单 | 内容 | 需要吗 |
|---|---|---|
| `downloads.json` | H3 Ref2VA 剪枝 int8（19.5GiB）、官方 NVFP4 文字编码器（14.6GiB）、影音 VAE | ✅ 必要 |
| `downloads_uncensored.json` | Qwen3-VL 32B Heretic int8 文字编码器（24.5GiB），原专案预设 | 看 [hardware.md](hardware.md) 的模型组合 |
| `downloads_vae_int8.json` | 影片 VAE int8（2.6GiB，目视无差） | 看 [hardware.md](hardware.md) |
| `downloads_dmad.json` | DMAD 4 步 LoRA（Diffusers 格式）→ 要转档，见下 | ✅ 必要 |
| `downloads_action_loras.json` | Combat_V2、GunFu、Motion_Repair、速度滑杆 | 选用 |
| `downloads_swap.json` | 换角色 v1.1、换头 v1.0（Alissonerdx，约 390MB，`h3_edit.py` 的 `recipe`） | 选用 |
| `downloads_funcontrol.json` | H3 Fun ControlNet（骨架控制）、SDPose | 舞蹈片才要 |
| `downloads_whitemodel.json` | 白模动作参考：SAM 3D Body、MoGe-3、SAM 3.1、RT-DETR v4（约 7.2GB，`tools/make_whitemodel.py`） | 舞蹈／武打照原片动作才要 |
| `downloads_qwen_turbo.json` | Qwen-Image 2.1 Turbo int8（7.3GB，`gen_image.py --turbo` 草稿模式） | 选用 |
| `downloads_facerefine.json` | 远景小脸精修：FL2VA 剪枝 int8、fl2v turbo 8 步 LoRA、`face_yolov8m.pt`（约 23GB，`tools/face_refine.py`） | 远景里有要认得出的角色才要 |
| `downloads_unpruned.json` | 未剪枝 H3（31.7GiB），实测跟剪枝版无差 | 不需要 |

> `destination` 写的是 `C:/AI/H3/models/...`，路径不同就先改清单。

DMAD 转档（q/k/v 精确合并，转完会自我验证）：
```
C:\AI\H3\venv\Scripts\python.exe C:\AI\tools\dmad_lora_convert.py C:\AI\H3\ComfyUI-0.36.0\models\loras\dmad_raw\dmad_minimax_h3_4step_lora_critic.safetensors C:\AI\H3\ComfyUI-0.36.0\models\loras\dmad_h3_4step_lora_critic_comfy.safetensors
```

配乐 MiniMax Music 3（int8 DiT、pruned int8 文字编码器、DAV VAE）用 `downloads_music3.json` 下载。

唱词歌（选用，顺序见 `templates/song_yue2_v14/README.md`）：
- YuE2 int8（3.96 GB，放 ComfyUI 的 `models/checkpoints`）用 `downloads_yue2.json` 下载。ComfyUI 0.37 起内建 YuE2 节点，含 melody 模式。
- ACE-Step 1.5 XL 用 `downloads_acestep.json` 下载，约 29.9 GB：xl_sft、xl_turbo 各 9.97 GB，qwen_4b 文字编码器 8.38 GB，qwen_0.6b 1.19 GB，VAE 0.34 GB。只在 ComfyUI 0.40 实测过。

## 5. Breeze TTS 2（C:\AI\BreezeTTS）

照官方 repo 装在独立 venv；`tools\breeze_batch.py` 顶端写了程式库与权重路径。**权重非商用**。只用来设计新角色的参考音。

## 5b. BreezyVoice（C:\AI\BreezyVoice）

台词配音引擎，Apache-2.0。装法见 `AGENT_SETUP.md` 2d（Python 3.10＋uv、`--no-deps` 照 `setup\env\requirements_breezyvoice_venv.txt`、Windows 用 `setup\breezyvoice\winstub` 取代 pynini）。原专案版本：程式 commit d592c9d、模型 `MediaTek-Research/BreezyVoice-300M` rev e33b502、torch 2.7.1+cu128、onnxruntime-gpu 1.23.2、transformers 4.45.2、g2pw 0.1.1（`num_workers=0`，否则 Windows 卡死）。

## 6. OpenAI Image 2.5

```
setx OPENAI_API_KEY "sk-..."
```
或把金钥放在专案外的文字档，设 `OPENAI_KEY_FILE` 指向它。`img25.py` 不会印出金钥。
可调：`IMG25_QUALITY`（预设 medium）、`IMG25_REF_SCALE`（预设 0.707，参考图缩成一半面积；角色不像时设 1 比对）。

## 7. 环境变数总表

| 变数 | 用途 | 预设 |
|---|---|---|
| `COMFY_HOST` | ComfyUI 位址（`h3_shot.py`） | `http://127.0.0.1:8188` |
| `COMFY_DIR` | ComfyUI 资料夹（`h3_shot.py`） | `C:\AI\H3\ComfyUI-0.36.0` |
| `H3_UNET` | H3 主模型档名 | 剪枝 int8 |
| `H3_CLIP` | H3 文字编码器档名 | Heretic int8 |
| `H3_VIDEO_VAE` | 影片 VAE | fp16 |
| `COMFY_EXTRA_ARGS` | `start_comfy` 额外启动参数 | 空 |
| `H3_ATTENTION` | `pytorch` 关掉 kitchen 注意力 | kitchen INT8 |
| `OPENAI_API_KEY`／`OPENAI_KEY_FILE` | Image 2.5 | — |
| `IMG25_QUALITY`、`IMG25_REF_SCALE` | Image 2.5 画质、参考图缩放 | medium、0.707 |

你的硬体该用哪些值，已经写在 `configs\profile.cmd`；每次开命令列视窗先 `call configs\profile.cmd`，再执行 `tools\start_comfy.cmd`。

## 8. 字型

脚本用 Windows 内建字型：微软正黑（`msjh.ttc`、`msjhbd.ttc`）、标楷体（`kaiu.ttf`）。
