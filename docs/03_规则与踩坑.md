# 03 规则与踩坑

每条规则都来自一次实际退件或实测。理由写在后面，改规则前先看理由。

## 1. 剧本

| 规则 | 理由 |
|---|---|
| 16:9、24fps、每支独立成篇 | 频道规格；24fps 也是将来训 LoRA 的前提 |
| 开写前先问齐人物、场景、走向、风格、禁则 | 最大的浪费是批次生成完才发现共通缺陷 |
| 先给 2–3 个叙事方向再写 | 一次验收合格的片都是这样开始 |
| 写看得见的行动；反转要能从前文线索回看成立 | 不要用解说对白代替戏 |
| 技术限制就是写作限制：避开快打、追逐，一镜一人说话 | H3 多人对话容易配错嘴，快动作会崩 |
| 喜剧用「神话层 × 真相层」，靠切镜制造反差 | 只靠旁白解释笑点的版本被退件 |
| 校内角色不用手机；老师不碰学生（关心用表情、手放桌上） | 场域观感 |
| 上课镜背景一定有同学；角色不随年级长大 | 退件项目 |
| 总结句用简单常用字 | TTS 比较不会念错 |

## 2. 空间与构图

| 规则 | 理由 |
|---|---|
| 教室方位固定：黑板在前、学生面向黑板、窗在学生左手边 | Image 2.5 自由构图曾让学生背对黑板 |
| 布置图当 Image 2.5 参考，提示词写「只抄机位与站位，不抄方块外观」 | 锁住空间 |
| 不同视角的首帧从**同一张底图**编辑；首尾帧也从同一张图改 | 换机位后背景会跑掉 |
| 不让人物横向走，改原地转身 | H3 会跟拍，桌椅跟著滑 |
| 空景、时钟、桌面特写用静图＋慢推 | H3 会自己加人或切走 |
| 单人镜提示词完全不提其他人；多人镜写 `Exactly N people` | 提到谁谁就会冒出来 |
| 舞蹈等大动作的主角镜：腰上或更近（脸占画高 10% 以上） | 768p 全景脸糊，放大救不回 |
| 一般远景照拍；脸 < 50 px 的重要角色放大前跑 `tools/face_refine.py`（选用，2026-10-24） | 追脸后用 H3 低强度重画脸、只贴回脸：25–30 px 的脸变得认得出本人；放大器（VSR、FlashVSR）救不回 |
| 提示词必写 `NO black letterbox bars` | 电影感提示词会自带黑边 |

## 3. 角色一致性

| 规则 | 理由 |
|---|---|
| 每个角色一组：定妆照、转面图（正侧背 3/4）、6 格表情表、**锁定提示词** | 每次照抄锁定提示词，不自己重写外观 |
| **本地生图的参考图只能是单张半身照**，不能用多格定妆表 | Qwen 会把多格版面照抄成拼贴 |
| 本地首帧不训练时用 Qwen-Image-Edit 附参考图；不要用 Qwen-Image 2.1 附参考图 | 2.1 附参考图会锁死成参考图的正面姿势 |
| 生图时以定妆照当 Image 2.5 参考图 | 比 LoRA 简单，效果够 |
| 头套写「素色美洲狮、无条纹、无斑点、无鬃毛、布偶绣眼」 | 不写会变老虎 |
| 头套加「a lifeless prop whose sewn face and eyes never move」 | H3 会让道具眨眼 |
| **多人镜只给首帧**，不加 H3 身份参考图 | 加了会多一个人 |
| 单人镜才加身份参考，并写明「只是外观参考，不是要切过去的画面」 | 否则 H3 会自己切镜 |
| 低头、转身、再露脸 → Image 2.5 生尾帧锁住 | 否则脸会换人 |
| 小孩要明显是 11–12 岁（写 childish face, never a teenager） | 第一版小雯像 16 岁 |

## 4. H3

| 规则 | 理由 |
|---|---|
| 一律用 `h3_shot.py`（官方 Ref2VA 六段格式＋格式检查） | 规格一致；手写容易漏段、标签错 |
| **`action` 写 50–120 字**：「Starting from <Picture 1>, …」首帧定锚→动作开始→持续发展→结果，写身体部位、幅度、次数，不写抽象形容词（官方 `h3-prompt-writing` 结构；2026-10-23） | 一句话版动作量只有 1/2.7，H3 照字面演，写「夸张」它不知道多大 |
| 动作镜首帧画「动作开始前」的姿势；弹跳等大动作首帧留头顶空间 | 首帧已是动作最高点就只剩维持可演；跳太高头出框、中段糊 |
| 预设只给首帧；长连续动作或一定要演到某个结果才加尾帧 | 对话与换场靠切镜 |
| 尾帧机位构图与首帧完全一样，但**必须是不同的图**（人要动时＝动作完成后的姿势） | 构图不同会摇镜去对；同一张图会把人锁回原姿势、画面冻住（2026-10-23 再次实测：三种写法都 100% 静止）。只有人不用动、只锁道具或萤幕字时才用同一张 |
| 没锁尾帧加「LOCKED-OFF STATIC CAMERA on a tripod」 | 否则镜头自己漂走 |
| `draft: true`（DMAD 4 步）是日常定稿；抽到就用，不要同 seed 改 14 步重生 | 8 类镜头并排看不出差、快 49–58% |
| 14 步留给：骨架舞蹈、群舞、细腻表情、Combat LoRA 拉满 | 这几类 DMAD 动量偏少或未验证 |
| 特效「碎掉／消失」加 Image 2.5 尾帧 | 只给首帧 H3 不会做 |
| 定稿不开 EasyCache | 近景糊、静止镜出油画杂讯 |
| 单镜 ≤12 秒（约 294 格）；短插入镜也至少生 5 秒再剪 | 15 秒会漂移、自己切镜 |
| 不说话的脸给静音引导音轨 | 否则会嘟囔 |
| 动作要「说到那个字的瞬间」发生（写进提示词） | 否则起立、敬礼慢半拍 |
| 长音：提示词写长音秒数＋「嘴维持张开到声音结束」 | H3 会提早闭嘴 |
| 舞蹈、武打：一镜到底＋**白模动作参考**（`make_whitemodel.py`，2026-10-14 起取代骨架控制；多人 `--colors`）＋首尾帧，最长 158 格 | 切片或用特写避开都被退件；白模比骨架准（手臂形状、踢脚、落地时间） |
| 动作 LoRA：Combat_V2 0.7、GunFu 0.9 | 实测有效；要保住首帧时避开 Motion_Repair 高强度 |
| H3 不要和别的 GPU 工作同时跑 | 抢显存，慢约 10 倍 |
| 计时看 ComfyUI `/history` 的执行时间，不看墙钟 | 伫列共用时墙钟不准 |
| 不换成社群微调模型 Singularity V2（2026-10-24 A/B：6 镜 × 2 seed＋动作镜 14 步，同首帧同 spec 只换权重） | 动作大 1.5–2.4 倍、速度一样，但①角色参考音念出来比较不像本人（双人镜 0.45–0.61 → 0.32–0.42）②推掌镜 3／3 支把首帧后墙换成写满中文的黑板、1 支冒出旗子（构图相关系数抓不到）③配角换脸、暖光变冷蓝。要动作大，改 `action` 写法就有 ×2.7 |
| SelfLift 两段采样（前段低解析、后段全解析）暂不用 | 只省时间不加画质；DMAD 只有 4 步可省的少；直式前段只剩约 307×538；外挂没有授权档 |
| **Veda 稀疏注意力不开**（`h3_shot.py` 预设关）；拍完跑 `flashcheck.py --clips <资料夹>` | 开了会让整个画面在第 51／119／187 格闪一下（2026-11-02，17 镜有 10 镜闪；关掉 0 闪、慢约 23%） |
| 限制句加「no flags, banners or national emblems」；拍完跑 `clipcheck.py` 抓自己切镜 | H3 会在 1–2.4 秒自己切镜，常切到墙上挂旗子、贴红色标语的教室；没台词的短反应镜最常发生 |
| soundscape／setting 不写 crowd、chatter、murmuring、students | 会把人画进背景，锁尾帧也挡不住 |
| 近景背后贴墙、门或柜子，不留空地或走廊 | H3 会让路人走进空地，限制句挡不住 |
| 背对镜头的镜查左右手；不演戏的那只手藏进袖子或口袋，首帧写明只看得到哪一只手 | 从背后拍常把左手画成右手 |
| H3 念的台词，称呼后面不标逗号（字幕再补回） | 「老师，」常在逗号停约 1 秒 |
| H3 念的台词开头不放「……」；要停顿写「嗯，」 | H3 会在那段空白念乱语 |
| （选用）重抽、尾帧、换首帧都修不好的坏镜（背景冒人、冒旗子、冒道具），最后才用 Google **Gemini Omni 1.2 Flash** 改片：上传该镜＋「Remove X. Keep everything else exactly the same.」（Google Flow 或 API）。只当修片工具，不拿来生成正片 | 作者实测（2026-11-07/08）：横式片能修干净（走廊学生全消失、主角不变）；**直式上传片 5/5 被挡**（不给原因、不扣点）；会整个画面重画（脸相似度 0.85–0.93），有台词要再查嘴型与声音；成本约是 Colab 跑 H3 的 16–35 倍（API 720p 每秒 0.07 美元），也不能给角色参考音 |

## 5. 配音与发音

| 规则 | 理由 |
|---|---|
| **（2026-10-23 起预设）画面内的台词让 H3 拿角色参考音自己念**：spec 写 `"audio": {"voice_ref": {"subject": "<说话者>", "file": "ref_<角色>.wav"}}`；两三人对话可同镜：写 `"voice_refs": [{"subject": ..., "file": ...}, ...]`（最多 3 位，各给参考音，每句台词自动写明用哪段音色） | 原频道 RTX 5090 实测（同一场戏三镜，对照 TTS 固定音轨、H3 无参考、云端 Seedance 2.5）：像参考音 0.66（TTS 0.68）、三镜一致性 0.75（最高）、表演比固定音轨生动、台词全对。两人同镜（2026-10-23，2 seed）：第二位说话者像本人 0.10 → 0.45、听写与嘴型都对。本 repo 范本 2026-10-24 从头实测：RTX 5090、7 镜 6 句台词 H3 全部念对、成片自审五遍通过、整支 27 分钟 |
| H3 自己念的镜头**逐镜听写比对原文**、同镜抽 2 个 seed；抽 2–3 次都不对才改 BreezyVoice 固定音轨 | H3 会改成大陆用词（「二十四号」→「二十四日」）、偶尔晚约 2 秒开口（剪接裁掉）；不能用注音逐字修 |
| BreezyVoice 固定音轨（`make_breezyvoice.cmd`）改当**备案**：念错抽不出来、数字日期难字、要精准时间点的声画同步 | 2026-10-07 整片 53 句实测：台湾国语腔调分数 0.85，旧做法（Breeze／VoxCPM2）0.80；每句约 2.5 秒、显存约 2GB。以下各条是 BreezyVoice 的做法 |
| （选用，原专案 2026-10-29 起的固定音轨预设）**Ming-3.0-TTS 0.5B**：`make_ming.cmd jobs.json`（格式同 BreezyVoice）。**一定要喂简体字**（工具用 OpenCC `t2s` 自动转，不要用 `tw2sp`，会换成大陆用词）；Ming 会**太早收尾**（最后一个字被切、逗号后的短句不见）→ 句尾改「……」（工具补抽时自动改）；逗号后别放太短的句子；克隆模式不能加语气指令，要表演用行内标签 `[Sigh]`／`[Laughter]` | 原专案 2026-10-28 实测（三角色各 3 句、4 seed）：9 句全对、候选 31/36 合格（Breeze 12/35）、像参考音 0.86（Breeze 0.81）；喂繁体每支都念错（线上报名→宪章奉明）；「…交到教务处。」4/4 句尾被切，改「……」3/3 完整。MIT 可营利 |
| 角色参考音定了就不要换（已公开的角色换声音观众听得出来） | 声音是角色的一部分 |
| 参考音不要升调或变速处理 | 处理过的参考音会念不准 |
| 成品不用 Edge-TTS，它只当「标准台湾国语答案卷」 | 声音不够自然 |
| （VoxCPM2 备用时）繁转简再送 | 繁体字读音较不稳 |
| 每句 8 个候选，`breezyvoice_pick.py` 自动挑：听写的**拼音＋声调**要全对（同音字不算错），有声长度合理，再比台湾国语腔调分数 | ASR 只验字，抓不到声调；ASR 常把角色名写成同音字 |
| 念不准的字**直接标注音**：`连假[:ㄐㄧㄚ4]`（标在字后面，声调用数字），字幕用原文；常见的已内建在 `breezyvoice_batch.py` 的 `TW_BOPO` | BreezyVoice 支援注音标记，不必再找同音字（旧做法：扫→嫂、综→纵） |
| 阿拉伯数字会自动转国字；小数、英文缩写请写成国字 | Windows 版没有文字正规化 |
| **单字台词（例：「考。」「接！」）尽量改成两三个字** | VoxCPM2 单字常念成乱音；BreezyVoice 的单字喊叫 ASR 会听成别的字（「接」→「姐」），只能人耳判断 |
| 听写（ASR）不对的候选一律不准选；抽 8 个都不对就改台词 | 否则挑音程式会从一堆错的里挑一个 |
| 挑音的「标准台湾国语答案卷」用 edge-tts；没网路才用 Breeze | 两者挑出的第一名只有 4/19 句相同，原专案验收过的是 edge-tts |
| 重要句最后请人听一次 | 自动量测在小音量下不可靠 |
| 每幕检查台词时间轴有没有重叠 | 旁白曾和广播叠在一起 |

## 6. 音效与配乐

| 规则 | 理由 |
|---|---|
| 有动作、**而且看不到嘴**（背影、脚、手、远景）的镜头，可以用 H3 原生音效（spec 不写 `audio` 栏位） | H3 的脚步声和画面逐格同步 |
| **看得到脸的镜头一律不要让 H3 自由出声**：有台词给角色参考音（H3 念该句）或备案配音，没台词给静音固定音轨，就算有动作也一样；需要动作音效时，另外用同一张首帧拍一支原生音效版，ASR 确认没有人声后只取它的音轨，或用音效库 | 看得到脸时 H3 原生音效会让角色自己嘟囔（2026-10-07 实测：翻书包镜冒出「你去考古啊」） |
| H3 做不出的用 CC0 音效库（repo 的 `sfx/`，58 个 Freesound CC0），不用程式合成脚步、肚子叫 | 合成的很假 |
| 配乐纯器乐，`[Instrumental]` 约 14 个，分离后再用 | 会夹人声、太短 |
| 台词前后压配乐 | 战斗配乐会盖过台词 |
| 停顿处垫很轻的房间声；不要低频隆隆声 | 偏好 |
| 用了 MiniMax Music 3 要在片尾列名并注明 AI 生成 | 授权要求 |

## 7. 放大

| 规则 | 理由 |
|---|---|
| 近景、中景：768p＋RTX VSR ULTRA | 秒级、不改表演 |
| 全景、舞蹈：FlashVSR，逐镜检查多画的细节 | 较锐，但会幻觉细节 |
| 不用 SeedVR2、SoL-Refiner | 会改脸、改嘴型、改时钟 |
| 不用 VOSR2 逐格修脸（社群「H3 脸部修复」工作流的做法） | 是单张图片超解析、不看前后格，跟 SeedVR2 同类风险；要修小脸用 `face_refine.py`（H3 重画，有时间一致性） |
| 字幕不要先烧进低解析再放大 | 字会糊 |

## 8. 后制与剪接

| 规则 | 理由 |
|---|---|
| 画面上的中文一律后制；考卷等「道具上的字」由 Image 2.5 直接画再逐字核对 | H3 写字会变乱码 |
| 用 `ss` 裁掉开口前空白，不要拉长整镜 | 尾巴会被切 |
| 同机位接续的对话镜加 0.3 秒溶接 | 避免跳接 |
| 施法换场景要有魔法转场（漩涡＋光点＋光环） | 不能只硬切背景 |
| 变脸用光流变形或 H3 首尾帧连续变化 | 遮罩擦过去看起来像剪接 |
| 远景短、特写多；动作定格后直接接反应镜 | 节奏 |
| 审片附手机版 720p（<30MB） | 验收的人在手机上看 |

## 9. 踩坑 Top 25

| # | 坑 | 对策 |
|---|---|---|
| 1 | EasyCache 让近景糊、近乎静止的无声镜出油画杂讯 | 定稿不开快取 |
| 2 | 首尾帧用同一张图 → 画面几乎冻住 | 尾帧必须是不同的图 |
| 3 | 没锁尾帧，镜头自己摇走 | 三脚架固定句，检查首尾格构图 |
| 4 | 尾帧构图和首帧不同 → H3 摇镜去对 | 首尾帧从同一张图编辑，只改动作 |
| 5 | 多人镜加身份参考 → 多一个人 | 多人镜只给首帧 |
| 6 | 附角色设定图 → H3 一镜内自己切镜 | 写明只是外观参考 |
| 7 | 低头或转身后脸换人 | 尾帧锁脸 |
| 8 | 提示词提到其他人 → 空教室冒人、出现两个老师 | 单人镜不提旁人、`Exactly N people`、换 seed |
| 9 | 无台词的脸自己嘟囔；多人镜嘴型配到错的人 | 静音引导；说话者放前景最大 |
| 10 | 开口晚 1.4–2.8 秒 | `ss` 裁头 |
| 11 | 长音提早闭嘴 | 提示词写长音秒数；用能量（−35 dB）量真正结束点 |
| 12 | 镜头露出黑板就写乱码字 | 尾帧锁定、扫全部格、换 seed |
| 13 | 15 秒镜头漂移、自己切镜 | ≤12 秒 |
| 14 | 三人正面踢腿几乎每个 seed 都长第三条腿，缩图看不出来 | 拆单人镜；看原解析度高峰格 |
| 15 | 骨架时间轴不够长，结尾被补成标准站姿 | 收尾段用最后一格填满＋尾帧 |
| 16 | 靠提示词指定哪只脚，结果左右反了 | 骨架或尾帧锁定 |
| 17 | 768p 全景脸糊 | 大动作主角腰上以上；一般远景小脸用 `face_refine.py` 修 |

## Windows 小坑

- ffmpeg 9 不支援 `-filter_complex_script`，改 `-/filter_complex`。
- drawtext 字型路径的冒号要跳脱：`C\\:/Windows/Fonts/...`。
- faster-whisper 缺 cuBLAS DLL：把 venv 里 `nvidia/*/bin` 加进 DLL 路径（`stt.py` 的 `_add_cuda_dll_dirs()`）。
- 标楷体用 `kaiu.ttf`；`mingliub.ttc` 是 ExtB 字集，一般字会变方块。
