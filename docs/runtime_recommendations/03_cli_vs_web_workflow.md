# 专题三：交互模式演进建议（Web 网页端 vs CLI 命令行）

在 LoPy 接入 Google Colab 算力后，系统提供了两种完全不同的交互运行界面：
1. **浏览器图形化笔记本**：[colab_lopy_pipeline.ipynb](file:///home/debian/lopy_project/lopy-workflow-colab/colab_lopy_pipeline.ipynb)
2. **本地纯命令行调度工具**：`cloud/colab_h3.py`

面对这两种模式，创作者应该如何选择？本文档提供清晰的**两阶段演进路线**。

---

## 一、 两种交互模式的核心差异对比

| 特性维度 | Web 交互式 Notebook (`.ipynb`) | 本地 Colab CLI (`colab_h3.py`) |
| :--- | :--- | :--- |
| **操作界面** | 网页浏览器（图形化单元格点击） | 本地 Linux/T4 终端命令行 |
| **画面直观度** | ⭐⭐⭐⭐⭐ **单元格内直接画中画播放成片** | ⭐⭐ 纯文本进度条，无视觉反馈 |
| **错误排查** | 友好，报错直接红字高亮在单元格下方 | 需查看日志文件或终端回显 |
| **防止意外扣费** | 依赖人工关闭标签页，易忘记关机 | ⭐⭐⭐⭐⭐ **跑完自动执行 `--stop-after` 关机** |
| **批量自动化** | 适合 1~4 镜头的交互式测试 | ⭐⭐⭐⭐⭐ **适合 10~50 镜头的大规模批量调度** |

---

## 二、 创作者的两阶段演进建议

我们强烈建议您根据项目的成熟度，遵循 **「初期 Web 调质感，成熟 CLI 跑批量」** 的演进策略：

### 阶段一：样片试跑与角色定妆期 ➔ 必用 Web 网页端 (`colab_lopy_pipeline.ipynb`)

* **适用场景**：
  - 项目刚启动，正在打磨前两集测试短剧；
  - 正在微调新角色的面部一致性与首帧提示词；
  - 正在调试台词的对嘴自然度与说话动作幅度。
* **核心优势**：
  - **所见即所得**：每一镜渲染完成后，Notebook 的单元格下方会立即弹出一个全功能 HTML5 播放器，您可以直接在手机或电脑浏览器中画中画循环播放；
  - 如果发现人物手势不对或眼神乱飘，可以在本地修改 Prompt 重新点击该单元格，几分钟内再次验证，反馈极度敏捷。

---

### 阶段二：剧本成型与规模化量产期 ➔ 全面切换至 Colab CLI

* **适用场景**：
  - 角色定妆卡已锁定，分镜表格已由 AI 编剧（`shanshiba-drama`）批量产出；
  - 需要连续生成多部短剧（例如一次性提交 20~40 个分镜）。
* **核心优势**：
  - **无人值守，杜绝空转浪费**：
    在本地敲下一行命令：
    ```bash
    python cloud/colab_h3.py batch S01/spec.json S02/spec.json S03/spec.json --stop-after
    ```
    Colab 实例会自动唤醒、高速拉取模型、并发渲染视频、自动将所有 `.mp4` 成片下载同步回本地 `runtime/outputs/`，并在**全部完成后自动关机**！
  - 即使创作者下班睡觉或外出，也绝对不会因为忘记关闭网页而导致 Colab 算力单元被白白扣光。

---

## 三、 实操切换指南

1. **初期**：
   - 上传 `colab_lopy_pipeline.ipynb` 到 Google Colab，挂载 Google Drive，手动点击运行各单元格。
2. **后期切换至 CLI**：
   - 在本地终端安装授权工具：`uv tool install google-colab-cli`；
   - 运行 `colab login` 进行一次性浏览器授权；
   - 即可在本地自由使用 `cloud/colab_h3.py` 调度云端算力。
