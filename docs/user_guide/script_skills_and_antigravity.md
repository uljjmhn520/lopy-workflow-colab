# AI 编剧技能与 Antigravity-CLI 联动实战指南

在 LoPy 工作流中，您**完全不需要从零手写分镜剧本**。系统内置了经过百万播放短视频打磨的 **AI 编剧 Skills（技能包）**，并与 **Google Antigravity CLI (`agy`)** 深度打通。

创作者只需在终端与 Antigravity AI 对话，就能自动产出完全契合 LoPy 规格（9:16 竖屏、6 段式动作、声画对嘴）的工业级分镜表。

| 技能名称 | 技能目录 | 适用创作场景 | 核心特色 |
| :--- | :--- | :--- | :--- |

## 二、 Antigravity-CLI (`agy`) 启动与基础操作

`antigravity-cli` 是 Google DeepMind 团队打造的高效终端智能体工具。

### 1. 启动命令行智能体
在项目根目录下打开终端，直接输入：
```bash
agy
```
即可进入交互式创作终端界面。

### 2. 常用 Slash 快捷命令速查
在 `agy` 对话框中，推荐搭配使用以下快捷指令：
* **/grill-me**（深度对齐）：让 AI 主动对您进行剧本深度访谈，逐步敲定核心冲突、角色反转与包袱，防止生成平庸剧情。
* **/plan**（分镜规划）：将剧本创意梳理为严密的 S01~S04 分镜执行计划。
* **/goal**（全自动闭环）：发布一个长任务，让 AI 编剧写完剧本后直接触发后台生图与视频渲染，不达目的不罢休。

## 三、 零门槛生成分镜实操口令（Copy & Paste）

进入 `agy` 后，您只需给出一句话灵感，并指明调用编剧技能：

### 场景范例 1：校园反转短剧（调用 `shanshiba-drama` 技能）
```text
请调用 shanshiba-drama 编剧技能。
我们要创作一部 15 秒、3 个镜头的校园搞笑反转短视频：
- 主角：小芸（学生）、林老师
- 场景：傍晚教室
- 冲突：小芸被查作业没带，找了个荒唐的借口，最后有出人意料的喜剧反转
- 要求：按 LoPy 标准分镜表格输出，包含角色、台词、符合 MiniMax H3 的 6 段式动作描述与固定机位。
```

#### AI 技能将自动为您输出标准交付分镜：
```markdown
| 镜号 | 角色名 | 角色台词 | 画面动作与运镜描述 |
| :--- | :--- | :--- | :--- |
| **S01** | 小芸 | “老师，我这次真的写完了，但作业本被我家猫吃了！” | 小芸坐在课桌前，神情心虚地猛地举起右手，身体微微前倾，眼神左右闪烁。窗外夕阳在她发丝勾勒出金色逆光。中景，LOCKED-OFF STATIC CAMERA。 |
| **S02** | 林老师 | “你觉得这种借口，老师会相信第二次吗？” | 林老师站在讲台旁，双手撑桌，单挑眉毛看着小芸，嘴角似笑非笑，眼神严肃。特写，Slow subtle push-in。 |
| **S03** | 小芸 | “真的！它甚至还在作业本上拉了一坨示威！” | 小芸满脸绝望委屈地从书包里掏出一包猫粮，双手抓狂甩动，表情夸张。近景，浅景深虚化背景。 |
```

## 四、 编剧技能的专业质检机制 (Checklist)

当 AI 编剧为您写完剧本后，Skills 内部会自动执行 **自审质检（Self-Review Checklist）**，确保交付给渲染引擎前 100% 合规：

1. **前 3 秒静音吸睛测试**：
   - 短视频用户前 3 秒经常静音划过，第一镜必须有强烈且醒目的肢体语言（如突然起立、猛拍桌子、慌张举手）。
2. **动作具象化过滤**：
   - 严禁出现“小芸内心波澜起伏”等抽象词汇，自动转译为“小芸双眼瞪大，咽了一口唾沫，手指绞紧衣角”等物理引擎可识别的画面。
3. **技术防崩保护**：
   - 单人镜绝不出现其他人名字（防止多长人脸）；
   - 台词避免生僻字、多音字歧义，确保语音模型发音精准。

AI 将全自动将其格式化为机器可读取的 JSON 配置文件，无缝衔接后续的语音合成与云端视频渲染！
