# LoPy 影视级工作流 - 创作者用户手册 (User Guide)

欢迎使用 **LoPy 自动化影视短片生成系统**。本文档专为**创作者、编剧、制作人与业务运营人员（非研发技术人员）**设计。

在这里，您无需关心显卡驱动、Docker 容器或复杂的 Python 代码；您是整个项目的**「总导演兼编剧」**，LoPy 系统则是您的**「全自动虚拟摄制组」**（自动包揽演员立绘、专业配音、真人级口型驱动、灯光运镜渲染、背景音效与后期剪辑）。

---

## 一、 创作者心智模型 (How It Works)

在整套系统稳定运转后，您的创作链路高度精简为公式：

$$\text{1 次角色形象/音色建档} + \text{每期 1 张文字分镜表格} = \text{批量自动化交付 9:16 短视频成片}$$

```text
 ┌────────────────────────────────────────────────────────┐
 │                      您提供的 INPUT                     │
 ├────────────────────────────┬───────────────────────────┤
 │ 1. 角色资产 (一次性建立)   │ 2. 分镜剧本 (每次只需写字)│
 │   - 角色标准定妆照         │   - 谁在说话 (角色名)     │
 │   - 参考音色 (3~5秒音频)   │   - 说了什么 (台词台本)   │
 │                            │   - 在干什么 (动作与情绪) │
 └─────────────┬──────────────┴─────────────┬─────────────┘
               │                            │
               ▼                            ▼
 ┌────────────────────────────────────────────────────────┐
 │           LoPy 全自动生产中枢 (您无需关心的黑盒)       │
 │   [AI配音] ➔ [AI画首帧] ➔ [AI视频渲染] ➔ [FFmpeg剪辑] │
 └────────────────────────────┬───────────────────────────┘
                              │
                              ▼
 ┌────────────────────────────────────────────────────────┐
 │                      最终交付 OUTPUT                   │
 │   - 一条制作精良、对准口型、带字幕音效的完整 9:16 成片   │
 └────────────────────────────────────────────────────────┘
```

## 三、 创作规格速览

- **默认画幅**：**9:16 竖屏**（原生 768×1344，适配抖音、微信视频号、小红书、TikTok、YouTube Shorts）。
- **帧率与标准**：24 fps 电影级帧率，音频标准响度 -16 LUFS（拒绝忽大忽小，符合各短视频平台播放标准）。
- **口型对齐**：全自动化声学模型驱动，单句台词对应人物嘴型自然闭合与运动，拒绝机械图层开合。
