# 创作者输出规格与交付物说明 (OUTPUT Spec)

当系统运行完毕后，所有产物都会保存在 `runtime/outputs/` 目录中（若连接了 Google Colab，会实时同步至您的 Google Drive `lopy_outputs/` 文件夹）。

LoPy 交付给您的不是零散的半成品，而是包含 **「即拿即发的成片」** 与 **「专业工程剪辑包」** 的双层工业级交付物。

---

## 一、 主交付物：最终成片 (`final_film.mp4`)

这是您可以直接上传至各大短视频平台的完整成品。

| 规格参数 | 交付标准 | 创作者体验与商业价值 |
| :--- | :--- | :--- |
| **画面画幅** | **9:16 竖屏**（基础 768×1344，可选 1080×1920） | 专为智能手机全屏沉浸感设计，无两侧黑边。 |
| **视频帧率** | **24 fps 电影级帧率** | 动作平滑且保持电影胶片呼吸感，非劣质 PPT 式卡顿。 |
| **编码格式** | H.264 / MP4 (CRF 14 高码率) | 全平台兼容，上传抖音/视频号不会被平台二次重压缩模糊。 |
| **对嘴精度** | **声学时间轴毫秒级贴合** | 人物嘴型开合、闭唇、长音延展与配音音波 100% 对齐。 |
| **音频混缩** | **标准响度 -16 LUFS (Stereo AAC)** | 经过自动压限与母带平衡，耳机/手机外放音量舒适纯净。 |
| **字幕压制** | 居中底部带黑边高清字幕 | 自动根据台词时间戳生成，免去人工逐字打轴痛苦。 |

---

## 二、 附带交付物：专业工程剪辑包 (方便二次剪辑与微调)

如果您有剪辑师配合，或者希望在**剪映 (CapCut)、Adobe Premiere Pro、DaVinci Resolve 或 Final Cut Pro** 中进行人工二创（例如替换特定流行 BGM、增加贴纸、局部调色），系统已将所有解耦素材打包规整：

```text
runtime/outputs/project_archive/
├── clips/                     # 每一个镜头独立的视频片段
│   ├── shot_01.mp4            # 第 1 镜：已对嘴、无背景音乐的纯净镜头
│   ├── shot_02.mp4            # 第 2 镜：已对嘴、无背景音乐的纯净镜头
│   └── shot_03.mp4            # 第 3 镜：已对嘴、无背景音乐的纯净镜头
├── audio/                     # 独立音频素材
│   ├── voice_isolated.wav     # 纯净对白人声音轨（无任何杂音与垫乐）
│   ├── bgm_track.wav          # 伴奏音乐轨
│   └── sfx_effects.wav        # 环境音效轨（开门声、碰撞声等）
├── subtitles/                 # 字幕工程文件
│   └── subtitles.srt          # 带有精准毫秒级入点与出点的 SRT 字幕文件
└── timeline.edl               # 剪辑工程交换文件（导入 PR / 剪映自动排好时间线）
```

---

## 三、 如何将工程包导入剪映 / Premiere？

1. **导入工程**：
   - 打开剪映或 Premiere，新建 9:16 (1080×1920) 项目；
   - 将 `clips/` 文件夹内的视频按顺序拖入轨道。
2. **导入字幕**：
   - 将 `subtitles/subtitles.srt` 直接拖入字幕轨，系统台词字幕瞬间自动就位。
3. **根据需要加料**：
   - 您可以直接保留系统混好的音效，也可自由添加抖音热门特效、转场音效或片头花字。
