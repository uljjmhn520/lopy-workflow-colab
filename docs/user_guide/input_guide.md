# 创作者输入准备指南 (INPUT Guide)

要在 LoPy 系统中制作一部影视级短片，您只需准备两项核心材料：**「角色资产卡」**（初次建立，永久复用）与**「分镜剧本表格」**（每期短片一份）。

---

## 一、 角色资产卡（一次性建立，多片复用）

如果您的短视频包含固定主角（例如自创 IP 角色“小芸”、“张总”、“李博士”等），需为每个角色建立专属资产目录：`runtime/chars/<角色英文名>/`。

### 1. 角色定妆肖像照 (`portrait.png`)
* **作用**：提供给系统作为最高优先级人脸与服装锁定基准。
* **要求**：
  - 格式：PNG，分辨率 1024×1024。
  - 内容：中景或半身正面照，五官清晰无遮挡，背景为纯浅灰或自然室内光。
  - 提示：如果您手头没有现成照片，可以向 AI 发送一句外貌描述（例如：“24岁东亚女性，干练黑色短发，内双眼皮，穿米白色休闲西装”），系统会自动生成 4 张候选肖像供您挑选，选中后即永久锁定。

### 2. 角色参考音色 (`voice_ref.wav`)
* **作用**：决定该角色说话时的音色、年龄感与语气风格。
* **要求**：
  - 格式：单声道 WAV，时长 **3 ~ 5 秒**。
  - 内容：一句咬字清晰、无背景杂音与混响的人声朗读音频。
  - 提示：系统已预置了普通话常用声音库（青年男声、干练女声、少年音、老教授音等），您可直接填写预置声音编号，免去录制烦恼。

---

## 二、 分镜剧本表格 (每期必备的核心文本)

您只需要提供一个清晰的文字表格（支持 Markdown、Excel 或飞书多维表格复制），定义每一镜的演职安排。

### 推荐标准剧本模板 (示例：15秒 3镜头短剧)

```markdown
# 短剧标题：作业消失事件
# 默认场景：高三年级教室，黄昏夕阳逆光
# 艺术风格：500T 柯达电影胶片质感，温暖色调，写实微颗粒

| 镜号 | 角色名 | 角色台词 (声音输入) | 画面动作与运镜描述 (视觉输入) |
| :--- | :--- | :--- | :--- |
| **S01** | 小芸 | “老师，我发誓……我真的写了作业！” | 小芸坐在课桌前，神情紧张地高举右手，身体微微前倾，眼神心虚闪烁。窗外夕阳在她发丝勾勒出金色轮廓。中景，固定机位。 |
| **S02** | 林老师 | “没带就是没写，你上周也是这么说的。” | 林老师站在讲台旁，双手抱胸，单挑眉毛看着小芸，嘴角挂着一丝好笑又严肃的微表情。特写，镜头缓慢微推。 |
| **S03** | 小芸 | “但这次真的是我家猫干的！它抓成碎纸条了！” | 小芸情绪激动地两手在胸前拼命挥舞解释，满脸委屈又焦急。近景，浅景深虚化背景。 |
```

## 三、 动作描述编写技巧（6段式金法则）

系统底层是由 MiniMax H3 物理引擎驱动人物动作的。想要画面最逼真，画面描述遵循**「看得见的具象行动」**原则：

> [!TIP]
> **好的动作描写（AI 能精准执行）**：
> - ✅ “小芸原本低着头，听到点名后猛地抬起头，惊慌地举起右手。”（有时序、有动作幅度）
> - ✅ “林老师眉头微皱，单手拿起红笔在教案上轻轻敲击了三下。”（有道具、有身体细节）
> 
> **需要避免的抽象描写（AI 无法量化）**：
> - ❌ “小芸感觉非常绝望，内心经历了激烈的思想斗争。”（AI 无法画出内心斗争）
> - ❌ “林老师以极其夸张搞笑的方式教育了学生。”（AI 不知道“夸张”是多大幅度）

### 运镜指示速查词：
* **固定机位**：`LOCKED-OFF STATIC CAMERA on a tripod`（最稳妥，人物动作最扎实）。
* **缓慢微推**：`Slow subtle push-in towards the character's face`（适合情绪推进或紧张时刻）。
* **景别标注**：特写（Close-up）、近景（Medium Close-up）、中景（Medium Shot）。短视频强烈建议以**中景与近景为主**，避免全景远景导致脸部过小。

---

## 四、 选填项（由系统默认预设接管）

以下内容如果创作者未特别指定，系统将直接采用工业级默认预设：
1. **背景音乐 (BGM)**：系统会根据剧情自动从开源商用音乐库中挑选契合的器乐垫乐（如校园温馨、紧张悬疑、欢快搞笑）。
2. **环境音效 (SFX)**：开门声、脚步声、翻书声、下课铃声，系统会根据剧本关键词自动插入音轨对应时间戳。
3. **字幕风格**：默认采用抖音/视频号爆款字幕规格（居中偏下、白字黑描边、醒目无衬线字体）。
