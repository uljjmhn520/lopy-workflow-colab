# 04 自审清单

原则：**交给人看之前，agent 自己先审完、修完**。人只负责主观判断（嘴型细节、语气、好不好笑）。

## review.py 五遍

```
H3 venv:    python review.py cut/<片名>_vN_1080p.mp4          # 第 1、3、4、5 遍
Voice venv: python review.py cut/<片名>_vN_1080p.mp4 --asr    # 第 2 遍
```

| 遍 | 检查 | 怎么判断 |
|---|---|---|
| 1 | 逐镜抽 4 格拼成总览图 | **一定要逐张人工看**：镜头漂移、多出人、脸换人、多手多脚、手没动、背景乱动、老师碰学生、学生面向 |
| 2 | 每句台词在成片里 ASR 一次 | 比对分数 <1 的逐句听；同音同调的辨识字错不算 |
| 3 | 色度杂讯 | >0.54 **且**比首帧高 25% 以上才警告（画面本身细节多不算） |
| 4 | 黑画面、定格（>0.8 秒不动）、响度、峰值 | −15.5 LUFS 左右、峰值 < −1.5 dBFS |
| 5 | 切点前后对照图、接点明暗差、台词重叠、台词被镜尾切掉 | 明暗差 >12 警告 |

## 常退件清单（人最常抓到的问题）

逐条确认，**不要让看片的人来抓**：

- [ ] 多腿、多手（踢腿高峰格要看原解析度）
- [ ] 手该动却没动
- [ ] 背景的人乱动、突然出现或消失
- [ ] 脸糊、脸换人
- [ ] 接点明暗跳、动作不连贯、硬切
- [ ] 台词重叠
- [ ] 念错字、声调怪、腔调不是台湾腔
- [ ] 道具乱飞（球飞走、纸消失）
- [ ] 多出人（尤其多一个老师）
- [ ] 头套变老虎、头套眨眼
- [ ] 黑板或纸上出现乱码字
- [ ] 上课镜背景没有同学
- [ ] 学生没有面向黑板、窗户换边

## 原则

- **不合格就重拍到合格**，不靠剪掉或插别的镜头躲。一批 6 个 seed 常常只有 1 个全过。
- 每支片至少看一张 100% 原尺寸全帧；只看缩图会漏判杂讯和第三条腿。
- 接点明暗要量成片，不量原始镜头（后制会改亮度）。
- 给人看**并排影片**，数字只当备注。人是用眼睛判断的。
- 技术 QA 通过 ≠ 使用者验收通过，两者分开记录。没量的东西（例如逐音素对嘴）照实写「没量」。
- 回报时用**成片时间码**对应镜头；没被点名的镜头不要动。

## 审片工具（2026-11-06 收录）

- `tools/framecheck.py <成片>`：每秒一格总表（每格 480 宽，看得出背景的人）。**每支片交出去前一张一张看**：背景冒人、糊掉、道具不连戏、墙上冒旗子。
- `tools/clipcheck.py <资料夹>`：逐镜算跟首帧的相关系数，< 0.7 标 CHECK＝H3 自己切镜或构图漂走。
- `tools/flashcheck.py --clips <资料夹>`：抓整个画面闪一下（Veda 造成）；成片模式 `flashcheck.py <成片> --tl timeline.json` 列出闪的影格与所在镜。

## 其他辅助工具（原专案有，未收录）

- `autocheck.py`：全身镜脸高 <80px、手没动（上下半身动态比）、背景乱动。
- `legcheck.py`：踢腿高峰格原解析度裁切。
- `accent_probe.py`：用语言辨识看「粤语」机率，抓港腔。
