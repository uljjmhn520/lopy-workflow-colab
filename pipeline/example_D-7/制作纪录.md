# 〈D-7〉制作纪录

> 剧本：[剧本.md](剧本.md)（v2）｜提案：[叙事方向.md](叙事方向.md)｜2026-10-04 起使用者授权「直接做到好、自己审」，审核依先前影片规则（五遍自审＋常退件清单）。

## 流程与程式

| 步骤 | 程式 | 说明 |
|:---|:---|:---|
| 布置图 | `blender/make_plan.py`、`blender/render_layouts.py` | 沿用动画版教室 `classroom_anim_p1.blend`（只读），13 个教室镜；成图镜射（窗在学生左手边），总览 `blender/布置图总览_v1.jpg` |
| 首帧 | `gen_frames.py` | Image 2.5 medium、n=1；房间母版 `ROOM_AH`／`ROOM_XW` 先生，再当参考；直式三分割小格 768×1344 |
| 配音 | `voice_plan.py`、`voice_stage1.py`、Breeze `breeze_batch.py`、`voice_pick.py` | VoxCPM2（繁转简）＋Breeze 克隆各 6 候选（小雯只用 Breeze 10 候选）→ ASR 全对 → 对照 edge-tts 台湾国语参考音挑声调最接近者 |
| H3 | `plan_h3.py`、`pipeline_gen.py` | 官方格式（`h3_shot.py`）、固定音轨（台词＋静音），S04／S08／S15／S20 让 H3 自己出环境音 |
| 后制素材 | `post_fx.py` | 撕日历字卡、咒印名片（栏内／全画面）、手机聊天画面、三分割灰／亮调色、角落时间字 |
| 剪接 | `assemble.py` | 三分割、三栏→四栏、配音／旁白／音效／配乐／字幕、响度 -15.5 LUFS |
| 配乐 | `music_scenes.py` | MiniMax Music 3 纯器乐三段（D-7／D-1／D-0） |
| 片尾 | `ending/config.json` | 频道片尾范本 |
| 自审 | `review.py` | 五遍：抽格／ASR／杂讯／黑格响度／切点 |

## 过程纪录

- 首帧第一轮 31 张；S03、S13、S19 老师背后出现教室后墙（应是黑板）→ 改用「从后方」教室参考并写明「黑板在他身后」重生；S02 小雯偏大、S15 手臂穿长袖 → 重生。
- 配音：「段考」ASR 常写成同音同调的「断考／断烤」→ 列为等价（不是念错）；V03 太快（7.3 字／秒）、V02／小雯 L02 偏慢 → 改用分数接近、语速自然的候选。
- 另一个 session 同时在用 ComfyUI 跑 H3（XA 镜），伫列交错，出片时间拉长。
- H3 第一轮 31 镜（直式 768×1344 小格可行，约 2–3 分钟／镜）；S07 阿禾低头后脸漂移、翘毛消失 → 改成一直面向镜头仍漂 → **Image 2.5 生尾帧＋首尾帧锁定**才稳定。
- v0 自审：S15 考卷标题字型 `mingliub.ttc` 是 ExtB 字集（显示方块）→ 改标楷；N4 第三栏残留名片 → 保存盖名片前的画面；三分割从黑画面滑入造成黑闪 → 改成盖在上一镜最后一格上滑入；S19 推近 1.65 倍。
- v1 自审：S01「下周段考喔」在下课背景音里被 ASR 听成「断卡」→ 台词时背景压到 30%、L01 改用在背景噪音下「考」仍最稳的候选并**重拍 S01**（换配音要重拍对嘴）；响度改两段式（loudnorm＋补增益＋限幅）。
- 教训：三师爸克隆声的「考喔」连读在噪音下容易被听成「口／卡」；挑配音时可先叠场景环境音再跑 ASR（`voice_robust.py`）。`upscale_vsr.py` 不会覆写旧档，重拍后要先删 `post/vsr/<id>.mp4`（assemble.py 已处理）。
