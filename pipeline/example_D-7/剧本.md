# 山狮霸・〈D-7〉

> v2 2026-10-04｜约 108 秒（不含片尾范本）｜16:9｜24fps｜小雯、阿禾（旁白兼入镜）、阿福、山狮霸（三师爸配音）
> 使用者定案：方案甲（倒数＋三分割画面），见 [叙事方向](叙事方向.md)。v2 修改（使用者 2026-10-04）：第四张名片改「昨天才出好题」；照建议删掉 D-3 段与「全班摸考卷」镜。v1 见 [剧本_v1备份](剧本_v1备份.md)。
> 角色外观、声音以 `角色资产/老师这次换你/` 为准。教室空间：黑板讲台在前、学生面向黑板、窗在学生左手边；阿禾第一排正中、小雯第一排靠走廊侧、阿福在阿禾斜后方（窗侧）；前门在走廊侧、靠黑板；上课期间背景一定有同学；桌肚开口朝座位。

## 设计核心

| 元素 | 做法 |
|:---|:---|
| **倒数字卡** | D-7 → D-1 → D-0，撕日历式字卡（后制） |
| **三分割画面** | 画面切成三直栏：左小雯、中阿禾、右阿福。**还没开始准备的那栏是灰的**（去饱和＋压暗），开始准备的那栏才「亮」成暖色 |
| **四字咒印名片** | 某一栏第一次亮起来的瞬间，在那一栏盖上名片：先知先觉／后知后觉／不知不觉。结尾第四张（全画面）：昨天才出好题 |
| **反转：第四种人** | 出题老师前一晚才印考卷。回看线索：①D-7 小雯问「下周四吗？」老师停了一拍才说「对」；②D-1 老师的笔电开著一片空白的文件；③D-0 老师拿著咖啡、眼睛有点红，考卷那叠冒著一缕热气（观众以为是咖啡）；④考卷是热的 |
| **人物互相牵动** | 小雯 D-7 晚上就把笔记传给阿禾；阿禾 D-1 凌晨才看到 |

## 剧本

**1. 内景・教室・下课**

画面文字（撕日历字卡）：「段考 D-7」

下课，教室吵吵闹闹。同学三三两两聊天。阿禾在第一排正中间折纸飞机，阿福在他斜后方撕开一包零食。小雯坐在第一排靠走廊的位子，桌上摊著联络簿。

山狮霸出现在教室前门，手里拿著马克杯。

山狮霸
下周段考喔。

教室没有人理他。只有小雯抬起头。

小雯
老师，是下周四吗？

山狮霸停了一拍。

山狮霸
……对。

他转身离开。小雯低头，在联络簿上一笔一画写下来。阿禾的纸飞机折好了。阿福把零食倒进嘴里。

阿禾（VO）
段考，有三种人。

画面一分为三。左栏小雯、中栏阿禾、右栏阿福。中栏和右栏褪成灰色，只有左栏是温暖的颜色。

画面文字（咒印名片，盖在左栏）：「先知先觉」

阿禾（VO）
第一种，先知先觉。一周前就开始。

**2. 内景・三人的房间・夜**

三分割画面延续。

左栏：小雯坐在书桌前，台灯亮著。她在读书计划表上打勾，接著拿手机拍下整理好的笔记，按下传送。

中栏（灰）：阿禾躺在床上打电动。

右栏（灰）：阿福抱著一大碗饭，吃得很满足。

阿禾（VO）
第二种跟第三种，那时候还没出现。

**3. 内景・教室・放学**

画面文字（撕日历字卡）：「段考 D-1」

放学，同学背起书包。山狮霸坐在讲桌后面，笔电开著，萤幕的白光照在他脸上。

山狮霸
明天段考。早点睡。

阿禾拉书包拉链的手停住。他慢慢抬起头，嘴巴张开。

画面一分为三。中栏的灰色一下子褪掉，亮起来。

画面文字（咒印名片，盖在中栏）：「后知后觉」

阿禾（VO）
第二种，后知后觉。也就是我。

**4. 内景・阿禾房间・深夜**

画面文字（角落小字）：「22:00」

阿禾坐在书桌前，课本、讲义堆成一座小山。他深吸一口气，卷起袖子。

阿禾（VO）
没关系。一个晚上，够了。

课本整页都已经被萤光笔涂成黄色，只剩最后一行还是白的。他拿萤光笔，慢慢拖过最后一行。

画面文字（角落小字）：「01:30」

阿禾趴在全黄的课本上，伸手拿起手机。

阿禾（VO）
跟班长借笔记好了。

手机画面——聊天列表。最上面是「游戏群组 999+」，下面一点是「小雯（1）」。他点开小雯。

手机画面——「上周四 21:03」，四张笔记照片，底下一行字：「我就知道你会问。」

阿禾的脸被手机萤幕照亮，一动也不动。

阿禾（VO）
……上周四。

**5. 内景・三人的房间・深夜**

三分割画面。

左栏：小雯的房间灯已经关了。她盖好被子，睡得很安稳。

中栏（亮）：阿禾的台灯亮著，他抱著头盯著课本。

右栏（灰）：阿福抱著枕头睡得很香，嘴角挂著口水。

阿禾（VO）
第三种人，睡得很好。

**6. 内景・教室・早自习**

画面文字（撕日历字卡）：「段考 D-0」

阿禾瘫坐在座位上，黑眼圈很深，脸颊上有一道萤光黄的笔痕。

小雯在削铅笔，笔一支一支排得整整齐齐。她看了阿禾一眼，嘴角轻轻翘一下，没说话。

阿福在后面开心地吃蛋饼。

山狮霸站在讲台，一手抱著一叠考卷，一手拿著咖啡，眼睛有点红。考卷那叠上方飘著一缕白白的热气。他把考卷一叠一叠放到第一排的桌上。

考卷往后传。阿福接过来，笑嘻嘻地往后传。

阿福
又有学习单～

他低头看自己那张。

画面文字（考卷标题）：「第一次段考　数学」

阿福的笑容停在脸上。

阿福
……今天，段考？

画面一分为三。右栏最后一个亮起来。

画面文字（咒印名片，盖在右栏）：「不知不觉」

阿禾（VO）
第三种，不知不觉。

**7. 内景・教室・段考中**

阿福把手掌平放在考卷上，愣了一下。

阿福
老师，考卷……是热的。

山狮霸推了一下眼镜，挑眉、半闭眼、抿嘴，一副「又来了」的表情。

山狮霸
……开始作答。

阿禾（VO）
原来，段考有四种人。

画面从三栏挤成四栏，最右边多出一栏——

闪回——

**8. 内景・教师办公室・深夜**

画面文字（角落小字）：「D-1　02:47」

办公室只剩一盏台灯。山狮霸一个人站在印表机旁边，印表机一张一张吐出考卷。他打了一个长长的哈欠。

画面文字（咒印名片，全画面）：「昨天才出好题」

**9. 内景・教室・段考中**

回到教室。全班低头作答，只有沙沙的写字声。

阿福没有动笔。他把两只手掌平平贴在考卷上，闭上眼睛，笑得很满足。

阿福
……好温暖。

切黑。
