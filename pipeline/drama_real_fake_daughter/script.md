# 短剧剧本：《真假千金·初见交锋》 (The Real Heiress Returns)

## 一、 故事前提与人物设定

- **题材类型**：豪门真假千金 / 逆袭打脸 / 身份反转
- **核心场景**：苏家欧式奢华会客厅（水晶吊灯、大理石长茶几、真皮复古沙发）
- **画幅规格**：9:16 竖屏（768×1344 @ 24fps）
- **预估片长**：4 镜约 16~18 秒

### 核心出场人物：
1. **顾初（真千金，22岁）**：
   - **外貌服饰**：清冷倔强的骨相美人，乌黑长发低马尾，未施粉黛却五官精致如雕刻；身穿洗得微微泛白的浅灰棉麻素色衬衫与深蓝牛仔长裤，身形笔挺如松，眼神如刃，毫无小门小户的怯懦。
   - **声线**：清冷、平稳、带有一丝讥诮与穿透力的年轻女声。
2. **苏晚晚（假千金，22岁）**：
   - **外貌服饰**：粉白相间的高定名媛软纱裙，珍珠耳坠，微卷栗色长发，妆容精致；表面眼眶微红、楚楚可怜、双手挽着苏夫人，实则嘴角暗藏得意与讥讽。
   - **声线**：柔弱娇嗲、带哭腔却字字带刺的绿茶名媛女声。
3. **苏夫人（豪门母亲，48岁）**：
   - **外貌服饰**：深墨绿暗纹丝绒旗袍，披米白羊绒披肩，戴帝王绿翡翠手镯与珍珠项链，端坐在主位单人真皮沙发上，神态高傲冷漠，眼神偏袒。
   - **声线**：威严、冷漠、高高在上的贵妇声线。

## 二、 4 镜分镜脚本与台词时序

```
[S01] 苏晚晚·先声夺人 (绿茶抢占道德高地) ───► [S02] 顾初·冷傲反击 (当场戳穿伪装)
                   │                                             │
                   ▼                                             ▼
[S03] 苏夫人·偏袒责难 (厉声维护假千金)   ───► [S04] 顾初·绝杀反转 (甩出当年换婴真相)
```

### [Shot 1] S01: 苏晚晚·先声夺人
- **机位运镜**：中景微推，仰角微拍站在沙发旁依偎着苏夫人的苏晚晚。
- **画面动作**：苏晚晚用指尖轻轻抹眼角并不存在的眼泪，楚楚可怜地望向镜头前方的顾初，眼底深处掠过一丝得意的挑衅。
- **台词 (苏晚晚)**："姐姐，你终于回来了……你要是嫌我占了你的位置，我明天就搬走。"
- **音效打点**：低频钢琴轻悬疑铺底音。
- **时长**：约 4.8 秒 (115 帧)

### [Shot 2] S02: 顾初·冷傲反击
- **机位运镜**：正打反打中近景，平视定焦。
- **画面动作**：顾初孤身站在空旷奢华的大理石地面上，双手插兜，不仅丝毫不慌，甚至嘴角微微勾起一抹讥诮的冷笑，目光如炬扫向门口。
- **台词 (顾初)**："不用等明天，我看门口这箱子，不是早替我收拾好了吗？"
- **音效打点**：重音鼓点一记，打破虚伪客套。
- **时长**：约 4.2 秒 (101 帧)

### [Shot 3] S03: 苏夫人·偏袒责难
- **机位运镜**：主位沙发中景特写，微推进。
- **画面动作**：苏夫人脸色骤变，将白瓷茶杯重重往茶几上一搁，眉头紧皱，眼神满是嫌弃与厉色，冷冷地盯着顾初。
- **台词 (苏夫人)**："顾初！你刚进这个家门，就这么容不下晚晚？"
- **音效打点**：瓷杯猛烈碰撞大理石桌面声（Thud/Clack）。
- **时长**：约 3.6 秒 (86 帧)

### [Shot 4] S04: 顾初·绝杀反转
- **机位运镜**：英雄仰角特写，镜头极具压迫感。
- **画面动作**：顾初向前一步，从风衣口袋抽出一份牛皮纸封皮的亲子鉴定与私家侦探报告，冷冷甩在苏夫人面前的茶几上，气场全开俯视全场。
- **台词 (顾初)**："苏夫人别急着心疼，当年换掉我的幕后主使……正是她的亲生母亲。"
- **音效打点**：文件猛摔茶几声 + 刺耳悬疑反转弦乐（Dramatic Stinger）。
- **时长**：约 5.2 秒 (125 帧)
